# Relay Implementation Plan (Plan E)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land `crates/relay/relay-core` (host registry, pair manager, ciphertext forwarder, four capacity budgets, stuck-pair guillotine) and `crates/relay/relay-bin` (`cli-pocket-relay` executable: clap CLI, config, `/health` + `/metrics`).

**Architecture:** A single WebSocket endpoint handles two slot kinds, distinguished by subprotocol: `cli-pocket-relay-host/v1` for daemons, `cli-pocket-relay-client/v1` for clients. The relay never decrypts payload bytes — it routes opaque `RelayData` frames between matched pairs. A host registers under its `HostId`; a client opens an offer addressed at a `HostId`; on accept, a `PairId` is allocated and the two sockets are joined. Capacity is bounded along four axes (hosts, pairs, per-pair bytes/sec, per-pair queued bytes). A guillotine task scans for stuck pairs (no progress in N seconds) and closes them.

**Tech Stack:** `axum` 0.7.x for HTTP routes + WebSocket upgrade, `tokio-tungstenite` underneath, `tokio` 1.x sync primitives, `metrics` + `metrics-exporter-prometheus`, `clap` 4.x, `tracing`.

**Spec references:** `docs/superpowers/specs/2026-05-21-cross-platform-remote-terminal-design.md` § 7 (relay), § 8 (operations).

**Depends on:** Plan A (scaffold), Plan B (contract layer — `RelayCtrl` / `RelayData` / `PairId` / `OfferId` must exist).

**Self-contained constraints:**
- The relay sees only ciphertext. It must never invoke `NoiseSession::read_message`.
- Bounded everything: no unbounded `mpsc::channel`, no `Vec` that grows on bad-input.
- Per-task commits must leave both crates buildable.

## Task E3: Capacity Counters

**Files:**
- Modify: `crates/relay/relay-core/src/caps.rs`
- Create: `crates/relay/relay-core/tests/caps.rs`

Capacity is enforced along four axes:
1. `host_count` — number of registered hosts.
2. `pair_count` — number of live pairs (independent of hosts since a host can hold N pairs).
3. `bytes_per_sec_per_pair` — token-bucket rate, refilled every 100 ms.
4. `queued_bytes_per_pair` — total ciphertext waiting in either direction's outbound channel.

When any limit is exceeded, the offending pair is closed with `RelayCtrl::PairClose { reason: ByeReason::Overloaded }`.

```rust
use std::sync::atomic::{AtomicU64, AtomicUsize, Ordering};
use std::sync::Arc;

pub struct Caps {
    inner: Arc<CapsInner>,
}

struct CapsInner {
    max_hosts: usize,
    max_pairs: usize,
    max_bytes_per_sec: u64,
    max_queued_bytes: usize,
    hosts: AtomicUsize,
    pairs: AtomicUsize,
    rate_bucket: AtomicU64,
}

#[derive(Debug, Clone, Copy)]
pub struct CapsSnapshot {
    pub hosts: usize,
    pub pairs: usize,
    pub rate_remaining: u64,
}

impl Caps {
    pub fn new(
        max_hosts: usize,
        max_pairs: usize,
        max_bytes_per_sec: u64,
        max_queued_bytes: usize,
    ) -> Self {
        Self {
            inner: Arc::new(CapsInner {
                max_hosts,
                max_pairs,
                max_bytes_per_sec,
                max_queued_bytes,
                hosts: AtomicUsize::new(0),
                pairs: AtomicUsize::new(0),
                rate_bucket: AtomicU64::new(max_bytes_per_sec),
            }),
        }
    }

    pub fn try_add_host(&self) -> crate::RelayResult<HostTicket> {
        let prev = self.inner.hosts.fetch_add(1, Ordering::AcqRel);
        if prev >= self.inner.max_hosts {
            self.inner.hosts.fetch_sub(1, Ordering::AcqRel);
            return Err(crate::RelayError::OverCapacity("max_hosts"));
        }
        Ok(HostTicket {
            inner: Arc::clone(&self.inner),
        })
    }

    pub fn try_add_pair(&self) -> crate::RelayResult<PairTicket> {
        let prev = self.inner.pairs.fetch_add(1, Ordering::AcqRel);
        if prev >= self.inner.max_pairs {
            self.inner.pairs.fetch_sub(1, Ordering::AcqRel);
            return Err(crate::RelayError::OverCapacity("max_pairs"));
        }
        Ok(PairTicket {
            inner: Arc::clone(&self.inner),
        })
    }

    pub fn try_consume_rate(&self, bytes: u64) -> crate::RelayResult<()> {
        let mut current = self.inner.rate_bucket.load(Ordering::Acquire);
        loop {
            if current < bytes {
                return Err(crate::RelayError::OverCapacity("rate"));
            }
            match self.inner.rate_bucket.compare_exchange(
                current,
                current - bytes,
                Ordering::AcqRel,
                Ordering::Acquire,
            ) {
                Ok(_) => return Ok(()),
                Err(observed) => current = observed,
            }
        }
    }

    /// Called by a 1Hz refill task.
    pub fn refill_one_tick(&self) {
        self.inner
            .rate_bucket
            .store(self.inner.max_bytes_per_sec, Ordering::Release);
    }

    pub fn remove_host(&self) {
        self.inner.hosts.fetch_sub(1, Ordering::AcqRel);
    }

    pub fn max_queued_bytes(&self) -> usize {
        self.inner.max_queued_bytes
    }

    pub fn snapshot(&self) -> CapsSnapshot {
        CapsSnapshot {
            hosts: self.inner.hosts.load(Ordering::Acquire),
            pairs: self.inner.pairs.load(Ordering::Acquire),
            rate_remaining: self.inner.rate_bucket.load(Ordering::Acquire),
        }
    }

    pub fn clone_handle(&self) -> Self {
        Self {
            inner: Arc::clone(&self.inner),
        }
    }
}

pub struct HostTicket {
    inner: Arc<CapsInner>,
}
impl Drop for HostTicket {
    fn drop(&mut self) {
        self.inner.hosts.fetch_sub(1, Ordering::AcqRel);
    }
}

pub struct PairTicket {
    inner: Arc<CapsInner>,
}
impl Drop for PairTicket {
    fn drop(&mut self) {
        self.inner.pairs.fetch_sub(1, Ordering::AcqRel);
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::Arc;

use bytes::Bytes;
use cli_pocket_shared_proto::ids::HostId;
use parking_lot::Mutex;
use tokio::sync::mpsc;

/// Message sent from the relay router to a host's WS writer task.
#[derive(Debug)]
pub enum HostMsg {
    Ctrl(Bytes),
    Data(Bytes),
    Close,
}

pub struct HostSlot {
    pub host_id: HostId,
    pub tx: mpsc::Sender<HostMsg>,
}

impl HostSlot {
    pub fn new(host_id: HostId, tx: mpsc::Sender<HostMsg>) -> Self {
        Self { host_id, tx }
    }
}

#[derive(Default)]
pub struct HostRegistry {
    inner: Arc<Mutex<HashMap<HostId, HostSlot>>>,
}

pub struct HostRegistration {
    host_id: HostId,
    inner: Arc<Mutex<HashMap<HostId, HostSlot>>>,
}

impl HostRegistry {
    pub fn new() -> Self {
        Self::default()
    }

    pub fn register(&self, slot: HostSlot) -> crate::RelayResult<HostRegistration> {
        let mut g = self.inner.lock();
        if g.contains_key(&slot.host_id) {
            return Err(crate::RelayError::Protocol("host already registered"));
        }
        let host_id = slot.host_id;
        g.insert(slot.host_id, slot);
        Ok(HostRegistration {
            host_id,
            inner: Arc::clone(&self.inner),
        })
    }

    pub fn get(&self, host_id: &HostId) -> Option<mpsc::Sender<HostMsg>> {
        self.inner.lock().get(host_id).map(|s| s.tx.clone())
    }

    pub fn list_ids(&self) -> Vec<HostId> {
        self.inner.lock().keys().copied().collect()
    }

    pub fn clone_handle(&self) -> Self {
        Self {
            inner: Arc::clone(&self.inner),
        }
    }
}

impl Drop for HostRegistration {
    fn drop(&mut self) {
        self.inner.lock().remove(&self.host_id);
    }
}
```

- [ ] **Step 2: Implement `forward.rs`**

The forwarder is intentionally simple: each WS connection has one read task and one write task. The read task parses the discriminator byte, deserializes either `RelayCtrl` (handled inline) or `RelayData` (looked up in `PairManager`, sent into the other side's `mpsc`). The write task pulls from its `mpsc` and writes WS frames.

```rust
use std::sync::Arc;
use std::time::Instant;

use bytes::Bytes;
use cli_pocket_shared_proto::codec::{decode_relay_ctrl, decode_relay_data, encode_relay_ctrl};
use cli_pocket_shared_proto::relay::{
    PairCloseReason, RelayCtrl, RelayData, RelayDataSlot, RELAY_DISC_CTRL, RELAY_DISC_DATA,
};
use cli_pocket_shared_proto::ids::{HostId, PairId};
use futures_util::{SinkExt, StreamExt};
use tokio::sync::mpsc;
use tokio_tungstenite::tungstenite::Message;
use tracing::{debug, warn};

use crate::caps::Caps;
use crate::pairs::{Pair, PairManager, PairMsg};
use crate::registry::{HostMsg, HostRegistry};

pub async fn run_host_side<WS>(
    mut ws: WS,
    host_id: HostId,
    rx: mpsc::Receiver<HostMsg>,
    registry: HostRegistry,
    pairs: PairManager,
    caps: Caps,
) -> crate::RelayResult<()>
where
    WS: StreamExt<Item = Result<Message, tokio_tungstenite::tungstenite::Error>>
        + SinkExt<Message, Error = tokio_tungstenite::tungstenite::Error>
        + Unpin
        + Send
```

```rust
use std::time::{Duration, Instant};

use crate::pairs::{PairManager, PairMsg};

pub async fn run(pairs: PairManager, idle_seconds: u64) {
    let interval = Duration::from_secs((idle_seconds / 4).max(1));
    let threshold = Duration::from_secs(idle_seconds);
    loop {
        tokio::time::sleep(interval).await;
        let now = Instant::now();
        let to_kill: Vec<_> = pairs
            .list_for_sweep()
            .into_iter()
            .filter(|p| now.duration_since(*p.last_progress.lock()) > threshold)
            .collect();
        for p in to_kill {
            tracing::warn!(pair=?p.pair_id, "guillotine: closing stuck pair");
            let _ = p.host_tx.send(PairMsg::Close("stuck")).await;
            let _ = p.client_tx.send(PairMsg::Close("stuck")).await;
            pairs.remove(&p.pair_id);
        }
    }
}
```

```rust
use std::net::SocketAddr;
use std::sync::Arc;

use crate::caps::Caps;
use crate::config::RelayConfig;
use crate::http::{router, AppState};
use crate::pairs::PairManager;
use crate::registry::HostRegistry;

pub struct RelayServer {
    pub state: AppState,
    pub config: RelayConfig,
}

impl RelayServer {
    pub fn new(config: RelayConfig) -> Self {
        let registry = HostRegistry::new();
        let pairs = PairManager::new();
        let caps = Caps::new(
            config.caps.max_hosts,
            config.caps.max_pairs,
            config.caps.max_bytes_per_sec,
            config.caps.max_queued_bytes,
        );
        let metrics = Arc::new(crate::metrics::init());
        let state = AppState {
            registry,
            pairs,
            caps,
            metrics,
            config: config.clone(),
        };
        Self { state, config }
    }

    pub async fn serve(self) -> crate::RelayResult<()> {
        let addr = SocketAddr::new(self.config.listen.addr, self.config.listen.port);
        let listener = tokio::net::TcpListener::bind(addr).await?;
        tracing::info!(%addr, "relay listening");

        // Refill task
        let caps = self.state.caps.clone_handle();
        let _refill = tokio::spawn(async move {
            let mut tick = tokio::time::interval(std::time::Duration::from_secs(1));
            loop {
                tick.tick().await;
                caps.refill_one_tick();
            }
        });
        // Guillotine task
        let pairs = self.state.pairs.clone_handle();
        let idle = self.config.guillotine.idle_seconds;
        let _gull = tokio::spawn(async move {
            crate::guillotine::run(pairs, idle).await;
        });

        let app = router(self.state.clone());
        axum::serve(listener, app)
            .await
            .map_err(|e| crate::RelayError::Internal(e.to_string()))?;
        Ok(())
    }
}

// AppState requires Clone — derive it manually since Caps/handles are Arc-based:
impl Clone for AppState {
    fn clone(&self) -> Self {
        Self {
            registry: self.registry.clone_handle(),
            pairs: self.pairs.clone_handle(),
            caps: self.caps.clone_handle(),
            metrics: Arc::clone(&self.metrics),
            config: self.config.clone(),
        }
    }
}
```

```markdown
# 0004. Self-hosted Rust relay with trait abstraction

Date: 2026-05-21
Status: Accepted
Owners: cli-pocket

## Context
We need a relay so phones (NAT, hotel Wi-Fi) can reach desktops without
port-forwarding. The two realistic shapes are:
1. Self-hosted Rust binary you run on a $5/mo VPS.
2. Cloudflare Durable Objects (or similar serverless) for zero ops.

## Decision
Ship (1) as the v1 default. Keep the relay surface narrow enough that a CF DO
implementation could be added later behind the same `RelayCtrl` / `RelayData`
contract.

## Consequences
- Positive: zero vendor lock-in, deployable anywhere, easy local CI testing.
- Positive: relay sees only ciphertext; compromise = traffic-analysis only.
- Negative: each user must run/operate the relay (or trust a community one).
- Risk accepted: spam offers DoS — mitigated by per-host pair caps and
  by hosts only accepting offers from paired client public keys.
```
