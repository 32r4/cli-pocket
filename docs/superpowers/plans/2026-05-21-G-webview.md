# Webview Terminal Implementation Plan (Plan G)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the shared xterm.js-based webview (`webview/terminal/`) that renders a terminal session. It compiles to two distinct bundles via Vite: `dist/tauri/` (loaded by the Tauri apps in Plan H, bridged through `@tauri-apps/api`) and `dist/web/` (loaded by the web app in Plan I, bridged through the `cli-pocket-client-core-wasm` package).

**Architecture:** A single TypeScript codebase. Renderer = xterm.js + xterm-addon-webgl + xterm-addon-fit + xterm-addon-unicode11. A `ClientBridge` interface abstracts over the two transports: in Tauri mode, calls into `invoke('cli_pocket:*')` and listens with `listen('cli_pocket:event')`; in Web mode, awaits methods on a `CliPocketClient` instance from the wasm package. The renderer reads `Snapshot` + `since` deltas from `ClientEvent::TerminalOutput` and writes to xterm's parser. Input keystrokes go back through the bridge.

**Tech Stack:** Vite 5, TypeScript 5, xterm 5.x, xterm-addon-{webgl,fit,unicode11}, `@tauri-apps/api` (peer dep, only loaded in tauri build), `cli-pocket-client-core-wasm` (only loaded in web build).

**Spec references:** spec § 6 (renderer architecture).

**Depends on:** Plan A (workspace conventions — repo lives at `webview/terminal/`), Plan B (handoff for `Snapshot`/`DeltaSlice` JSON shapes), Plan F (handoff for the `CliPocketClient` JS API).

**Self-contained constraints:**
- This is a TypeScript subproject; it shares no Cargo workspace.
- Linting: ESLint + `@typescript-eslint`. Formatting: Prettier. Both configured by Plan A's `just check`.
- Tests: `vitest` for unit, Playwright for end-to-end (Playwright is OPTIONAL — defer to Plan I if v1 timeline tight).

## Task G4: TauriBridge Implementation

**Files:**
- Create: `webview/terminal/src/bridge/TauriBridge.ts`

The Tauri side uses `invoke('cli_pocket:<command>')` for RPC and `listen('cli_pocket:event')` for the event stream. Plan H wires these on the Rust side.

- [ ] **Step 1: Implement**

```ts
import type { ClientBridge, ConnectConfig } from "./ClientBridge";
import type { ClientEvent } from "@/types/events";

export class TauriBridge implements ClientBridge {
  private events_buffered: ClientEvent[] = [];
  private resolvers: Array<(ev: ClientEvent | null) => void> = [];
  private unlisten: (() => void) | null = null;
  private closed = false;

  static async create(): Promise<TauriBridge> {
    const b = new TauriBridge();
    const { listen } = await import("@tauri-apps/api/event");
    const off = await listen<ClientEvent>("cli_pocket:event", (e) => {
      b.push(e.payload);
    });
    b.unlisten = off;
    return b;
  }

  private constructor() {}

  private push(ev: ClientEvent) {
    if (this.closed) return;
    const r = this.resolvers.shift();
    if (r) r(ev);
    else this.events_buffered.push(ev);
  }

  async connect(config: ConnectConfig): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:connect", { config });
  }

  events(): AsyncIterable<ClientEvent> {
    const self = this;
    return {
      [Symbol.asyncIterator](): AsyncIterator<ClientEvent> {
        return {
          async next(): Promise<IteratorResult<ClientEvent>> {
            if (self.closed) return { value: undefined, done: true };
            const head = self.events_buffered.shift();
            if (head) return { value: head, done: false };
            const value = await new Promise<ClientEvent | null>((resolve) => {
              self.resolvers.push(resolve);
            });
            if (value === null) return { value: undefined, done: true };
            return { value, done: false };
          },
        };
      },
    };
  }

  async createTerminal(params: {
    cols: number;
    rows: number;
    cwd?: string;
    env?: Record<string, string>;
    shell?: string;
  }): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:create_terminal", { params });
  }

  async sendInput(terminalId: string, bytes: Uint8Array): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:send_input", {
      terminalId,
      // Tauri's bincode mapping converts Vec<u8> from a number[] argument.
      bytes: Array.from(bytes),
    });
  }

  async resize(terminalId: string, cols: number, rows: number): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:resize", { terminalId, cols, rows });
  }

  async kill(terminalId: string, signal: "TERM" | "KILL" | "HUP"): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:kill", { terminalId, signal });
  }

  async exportIdentity(): Promise<string> {
    const { invoke } = await import("@tauri-apps/api/core");
    return await invoke<string>("cli_pocket:export_identity");
  }

  async importIdentity(blob: string): Promise<void> {
    const { invoke } = await import("@tauri-apps/api/core");
    await invoke("cli_pocket:import_identity", { blob });
  }

  async close(): Promise<void> {
    this.closed = true;
    for (const r of this.resolvers) r(null);
    this.resolvers = [];
    if (this.unlisten) this.unlisten();
    const { invoke } = await import("@tauri-apps/api/core");
    try {
      await invoke("cli_pocket:close");
    } catch {
      // best-effort
    }
  }
}
```

- [ ] **Step 1: Implement**

```ts
import type { ClientBridge, ConnectConfig } from "./ClientBridge";
import type { ClientEvent } from "@/types/events";

interface WasmClient {
  connect(configJson: string): Promise<void>;
  next_event(): Promise<unknown>;
  create_terminal(paramsJson: string): Promise<void>;
  send_input(terminalId: string, bytes: Uint8Array): Promise<void>;
  resize(terminalId: string, cols: number, rows: number): Promise<void>;
  kill(terminalId: string, signal: string): Promise<void>;
  export_identity(): Promise<string>;
  import_identity(blob: string): Promise<void>;
  close(): Promise<void>;
}

export class WebBridge implements ClientBridge {
  private client: WasmClient;
  private closed = false;

  private constructor(client: WasmClient) {
    this.client = client;
  }

  static async create(): Promise<WebBridge> {
    // The wasm package exposes default-init and a CliPocketClient class.
    const wasmModule = await import(
      /* @vite-ignore */ "cli-pocket-client-core-wasm"
    );
    if (typeof wasmModule.default === "function") {
      await wasmModule.default();
    }
    const client = new wasmModule.CliPocketClient() as WasmClient;
    return new WebBridge(client);
  }

  async connect(config: ConnectConfig): Promise<void> {
    await this.client.connect(JSON.stringify({
      endpoint_url: config.endpointUrl,
      server_public_hex: config.serverPublicHex,
      resume_token_hex: config.resumeTokenHex ?? null,
    }));
  }

  events(): AsyncIterable<ClientEvent> {
    const self = this;
    return {
      [Symbol.asyncIterator](): AsyncIterator<ClientEvent> {
        return {
          async next(): Promise<IteratorResult<ClientEvent>> {
            if (self.closed) return { value: undefined, done: true };
            const raw = await self.client.next_event();
            if (raw === null || raw === undefined) {
              return { value: undefined, done: true };
            }
            return { value: raw as ClientEvent, done: false };
          },
        };
      },
    };
  }

  async createTerminal(params: {
    cols: number;
    rows: number;
    cwd?: string;
    env?: Record<string, string>;
    shell?: string;
  }): Promise<void> {
    await this.client.create_terminal(JSON.stringify(params));
  }

  async sendInput(terminalId: string, bytes: Uint8Array): Promise<void> {
    await this.client.send_input(terminalId, bytes);
  }

  async resize(terminalId: string, cols: number, rows: number): Promise<void> {
    await this.client.resize(terminalId, cols, rows);
  }

  async kill(terminalId: string, signal: "TERM" | "KILL" | "HUP"): Promise<void> {
    await this.client.kill(terminalId, signal);
  }

  async exportIdentity(): Promise<string> {
    return await this.client.export_identity();
  }

  async importIdentity(blob: string): Promise<void> {
    await this.client.import_identity(blob);
  }

  async close(): Promise<void> {
    this.closed = true;
    await this.client.close();
  }
}
```

```ts
import { applySnapshot } from "@/render/snapshot";
import type { Snapshot } from "@/types/frame";

describe("applySnapshot", () => {
```

```ts
import type { Terminal } from "xterm";
import type { Snapshot, AnchorState } from "@/types/frame";

export async function applySnapshot(term: Terminal, snap: Snapshot): Promise<void> {
  term.reset();

  const bytes = base64ToBytes(snap.bytes_b64);
  await writeAsync(term, bytes);

  const tail = encodeAnchorTail(snap.anchor);
  if (tail.length > 0) {
    await writeAsync(term, tail);
  }
}

function base64ToBytes(b64: string): Uint8Array {
  const bin = atob(b64);
  const out = new Uint8Array(bin.length);
  for (let i = 0; i < bin.length; i++) out[i] = bin.charCodeAt(i);
  return out;
}

function writeAsync(term: Terminal, bytes: Uint8Array): Promise<void> {
  return new Promise((resolve) => term.write(bytes, () => resolve()));
}

/**
 * Encode a minimal set of control sequences to set the parser state to match
 * the anchor. Plan B's AnchorState was designed so this stays simple — we
 * write:
 *   - title (OSC 2)
 *   - bracketed paste (CSI ?2004 h/l)
 *   - alt screen (CSI ?1049 h/l)
 *   - mouse mode (CSI ?100x h/l)
 *
 * The actual cursor position and SGR fall out of the byte stream we already
 * wrote; we do NOT replay SGR explicitly to avoid double application.
 */
function encodeAnchorTail(anchor: AnchorState): Uint8Array {
  const parts: string[] = [];
  if (anchor.title) parts.push(`\x1b]2;${anchor.title}\x07`);
  if (anchor.modes.bracketed_paste) parts.push("\x1b[?2004h");
  if (anchor.modes.alt_screen) parts.push("\x1b[?1049h");
  switch (anchor.modes.mouse) {
    case "click":
      parts.push("\x1b[?1000h");
      break;
    case "drag":
      parts.push("\x1b[?1002h");
      break;
    case "any":
      parts.push("\x1b[?1003h");
      break;
    case "off":
    default:
      break;
  }
  return new TextEncoder().encode(parts.join(""));
}
```

```ts
import { Terminal } from "xterm";
import { FitAddon } from "xterm-addon-fit";
import { Unicode11Addon } from "xterm-addon-unicode11";
import { WebglAddon } from "xterm-addon-webgl";
import { applyDelta } from "./delta";
import { applySnapshot } from "./snapshot";
import type { Snapshot, DeltaSlice } from "@/types/frame";

import "xterm/css/xterm.css";

export interface RendererOptions {
  fontFamily?: string;
  fontSize?: number;
}

export class Renderer {
  readonly terminal: Terminal;
  private fit = new FitAddon();
  private resizeHandlers: Array<(cols: number, rows: number) => void> = [];

  constructor(opts: RendererOptions = {}) {
    this.terminal = new Terminal({
      allowProposedApi: true,
      fontFamily: opts.fontFamily ?? "ui-monospace, SFMono-Regular, Menlo, monospace",
      fontSize: opts.fontSize ?? 14,
      cursorBlink: true,
      scrollback: 5000,
      convertEol: false,
    });

    this.terminal.loadAddon(new Unicode11Addon());
    this.terminal.unicode.activeVersion = "11";
    this.terminal.loadAddon(this.fit);
    try {
      this.terminal.loadAddon(new WebglAddon());
    } catch {
      // WebGL not available — fall back to canvas/dom renderer silently.
    }

    this.terminal.onResize(({ cols, rows }) => {
      for (const h of this.resizeHandlers) h(cols, rows);
    });
  }

  mount(container: HTMLElement): void {
    this.terminal.open(container);
    this.fit.fit();
    const ro = new ResizeObserver(() => this.fit.fit());
    ro.observe(container);
  }

  onData(handler: (data: string) => void): void {
    this.terminal.onData(handler);
  }

  onResize(handler: (cols: number, rows: number) => void): void {
    this.resizeHandlers.push(handler);
  }

  proposeDimensions(): { cols: number; rows: number } | undefined {
    return this.fit.proposeDimensions();
  }

  async applySnapshot(snap: Snapshot): Promise<void> {
    await applySnapshot(this.terminal, snap);
  }

  async applyDelta(delta: DeltaSlice): Promise<void> {
    await applyDelta(this.terminal, delta);
  }

  dispose(): void {
    this.terminal.dispose();
  }
}
```

```ts
/**
 * If bracketed paste mode is on, the renderer expects:
 *   ESC [ 200 ~ ... text ... ESC [ 201 ~
 *
 * We always send the bracketed sequence; the server-side parser flips the
 * brackets back into literal pastes if the mode is off.
 */
export function wrapBracketedPaste(text: string): Uint8Array {
  const enc = new TextEncoder();
  const start = enc.encode("\x1b[200~");
  const body = enc.encode(text);
  const end = enc.encode("\x1b[201~");
  const out = new Uint8Array(start.length + body.length + end.length);
  out.set(start, 0);
  out.set(body, start.length);
  out.set(end, start.length + body.length);
  return out;
}
```

```ts
  private renderer = new Renderer();
  private status = new StatusBar();
  private vkb = new VirtualKeyBar();
  private activeTerminalId: string | null = null;

  constructor(private bridge: ClientBridge) {}

  async mount(root: HTMLElement): Promise<void> {
    root.innerHTML = "";
    const wrap = document.createElement("div");
    wrap.className = "app";
    const termContainer = document.createElement("div");
    termContainer.className = "terminal-host";
    wrap.appendChild(this.status.element);
    wrap.appendChild(termContainer);
    if (CLIENT_KIND === "tauri" && isMobile()) {
      wrap.appendChild(this.vkb.element);
    }
    root.appendChild(wrap);

    this.renderer.mount(termContainer);
    this.renderer.onData((data) => {
      if (this.activeTerminalId) {
        const bytes = new TextEncoder().encode(data);
        void this.bridge.sendInput(this.activeTerminalId, bytes);
      }
    });
    this.renderer.onResize((cols, rows) => {
      if (this.activeTerminalId) {
        void this.bridge.resize(this.activeTerminalId, cols, rows);
      }
    });
    this.vkb.onPress((key) => {
      if (!this.activeTerminalId) return;
      const bytes = key;
      void this.bridge.sendInput(this.activeTerminalId, bytes);
    });

    void this.consumeEvents();
  }

  private async consumeEvents(): Promise<void> {
    for await (const ev of this.bridge.events()) {
      this.handle(ev);
    }
  }

  private handle(ev: ClientEvent): void {
    switch (ev.kind) {
      case "Connecting":
        this.status.set("Connecting…");
        break;
      case "Connected":
        this.status.set(`Connected (${ev.session_id.slice(0, 8)})`);
        break;
      case "Disconnected":
        this.status.set(
          `Disconnected${ev.will_retry ? " (retrying)" : ""}: ${ev.reason}`,
        );
        break;
      case "TerminalCreated":
        this.activeTerminalId = ev.info.terminal_id;
        this.status.set(
          `Terminal ${ev.info.terminal_id.slice(0, 8)} — ${ev.info.shell}`,
        );
        break;
      case "TerminalOutput": {
        const bin = atob(ev.bytes_b64);
        const bytes = new Uint8Array(bin.length);
        for (let i = 0; i < bin.length; i++) bytes[i] = bin.charCodeAt(i);
        this.renderer.terminal.write(bytes);
        break;
      }
      case "TerminalExited":
        this.status.set(
          `Exited code=${ev.info.code ?? "?"} sig=${ev.info.signal ?? "-"}`,
        );
        this.activeTerminalId = null;
        break;
      case "Error":
        this.status.set(`Error: ${ev.message}`);
        break;
    }
  }
}
```

```ts
import type { ClientBridge, ConnectConfig } from "./ClientBridge";
import type { ClientEvent } from "@/types/events";

export class MockBridge implements ClientBridge {
  private queue: ClientEvent[] = [];
  private resolvers: Array<(ev: ClientEvent | null) => void> = [];
  private closed = false;

  async connect(_config: ConnectConfig): Promise<void> {
    this.emit({ kind: "Connecting" });
    setTimeout(() => {
      this.emit({ kind: "Connected", session_id: "mock-session" });
      this.emit({
        kind: "TerminalCreated",
        info: {
          terminal_id: "mock-term-1",
          cols: 80,
          rows: 24,
          cwd: "/tmp",
          shell: "/bin/zsh",
          pid: 1234,
        },
      });
      const hello = new TextEncoder().encode(
        "\x1b[2J\x1b[H\x1b[32mWelcome to cli-pocket mock\x1b[0m\r\n$ ",
      );
      this.emit({
        kind: "TerminalOutput",
        terminal_id: "mock-term-1",
        stream_seq: 0,
        bytes_b64: bytesToB64(hello),
      });
    }, 100);
  }

  events(): AsyncIterable<ClientEvent> {
    const self = this;
    return {
      [Symbol.asyncIterator](): AsyncIterator<ClientEvent> {
        return {
          async next(): Promise<IteratorResult<ClientEvent>> {
            if (self.closed) return { value: undefined, done: true };
            const head = self.queue.shift();
            if (head) return { value: head, done: false };
            const value = await new Promise<ClientEvent | null>((resolve) => {
              self.resolvers.push(resolve);
            });
            if (value === null) return { value: undefined, done: true };
            return { value, done: false };
          },
        };
      },
    };
  }

  async createTerminal(): Promise<void> {}
  async sendInput(_t: string, bytes: Uint8Array): Promise<void> {
    // Echo back to the terminal.
    const echoed = new Uint8Array(bytes.length);
    echoed.set(bytes);
    this.emit({
      kind: "TerminalOutput",
      terminal_id: "mock-term-1",
      stream_seq: 0,
      bytes_b64: bytesToB64(echoed),
    });
  }
  async resize(): Promise<void> {}
  async kill(): Promise<void> {}
  async exportIdentity(): Promise<string> {
    return JSON.stringify({ version: 1, mock: true });
  }
  async importIdentity(_blob: string): Promise<void> {}
  async close(): Promise<void> {
    this.closed = true;
    for (const r of this.resolvers) r(null);
  }

  private emit(ev: ClientEvent) {
    const r = this.resolvers.shift();
    if (r) r(ev);
    else this.queue.push(ev);
  }
}

function bytesToB64(b: Uint8Array): string {
  let s = "";
  for (let i = 0; i < b.length; i++) s += String.fromCharCode(b[i]);
  return btoa(s);
}
```
