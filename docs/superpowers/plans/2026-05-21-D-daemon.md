# Daemon Implementation Plan (Plan D)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land `crates/server/daemon-core` (session manager, Noise XK acceptor, terminal routing, resume tokens, identity & client-DB hot reload) and `crates/server/daemon-bin` (the `cli-pocket-daemon` executable: clap CLI, config loader, signal-aware runtime).

**Architecture:** A WebSocket listener (using `crates/shared/transport`) accepts inbound connections; each accepted socket is handed to a per-connection task that runs the Noise XK responder (using `crates/shared/crypto`), looks up the client static key in `clients.json`, then enters the frame loop. Terminals are owned by a `SessionManager` keyed by `TerminalId`, with the PTY (`crates/server/pty`) as the IO engine. Resume tokens are HMACed (key = identity private bytes) and let a reconnecting client re-attach to an existing terminal subscription. A `notify`-driven file watcher reloads `clients.json` and the revocation list, dropping live sessions whose client_id is revoked.

**Tech Stack:** `tokio` 1.x, `tokio-tungstenite` 0.24.x (via `shared/transport`), `snow` 0.9.x (via `shared/crypto`), `portable-pty` 0.8.x (via `server/pty`), `clap` 4.x with derive, `serde_json`, `toml`, `notify` 6.x, `tracing` + `tracing-subscriber`, `directories` 5.x for default paths.

**Spec references:** `docs/superpowers/specs/2026-05-21-cross-platform-remote-terminal-design.md` § 1, § 3 (trust + identity), § 5 (daemon lifecycle), § 9 (CLI surface).

**Depends on:** Plan A (scaffold), Plan B (contract layer — proto/crypto/transport must be on `proto-v1.0.0-frozen`), Plan C (PTY).

**Self-contained constraints:**
- All file paths absolute from repo root.
- Daemon does not link the relay; the relay-aware reconnect path lives in `client-core` (Plan F).
- The daemon also speaks the relay-host protocol (registration + ciphertext forwarding); the relay-bound dialer is implemented here so the daemon can connect to a configured relay without depending on `relay-core`.
- Per-task commits leave the crate buildable: `cargo check -p cli-pocket-daemon-core` and `cargo check -p cli-pocket-daemon` MUST pass after every task.

```rust
pub struct DaemonConfig {

    pub port: u16,
}

impl Default for ListenConfig {
    fn default() -> Self {
        Self {
            addr: "127.0.0.1".parse().unwrap(),
            port: 7842,
        }
    }
}

pub struct SecurityConfig {
    pub identity_path: PathBuf,
    pub clients_path: PathBuf,
    pub revoked_path: PathBuf,
}

impl Default for SecurityConfig {

            .map(|p| p.data_dir().to_path_buf())

            clients_path: base.join("clients.json"),

    pub url: String,
    /// PSK hex; mixed into Noise at position 2.

    /// Optional bearer token presented as the WS subprotocol on the host slot.
    #[serde(default)]
    pub host_token: Option<String>,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct LimitsConfig {
    pub max_terminals: usize,
    pub scrollback_bytes: usize,
    pub scrollback_anchor_interval: usize,
    pub broadcast_capacity: usize,
}

impl Default for LimitsConfig {
    fn default() -> Self {
        Self {
            max_terminals: 64,
            scrollback_bytes: 2 * 1024 * 1024,
            scrollback_anchor_interval: 64 * 1024,
            broadcast_capacity: 1024,
        }
    }
}

impl Default for DaemonConfig {
    fn default() -> Self {
        Self {
            listen: ListenConfig::default(),
            security: SecurityConfig::default(),
            relay: None,
            limits: LimitsConfig::default(),
        }
    }
}

impl DaemonConfig {
    pub fn load_from(path: &std::path::Path) -> crate::DaemonResult<Self> {
        let text = std::fs::read_to_string(path).map_err(crate::DaemonError::Io)?;
        toml::from_str(&text).map_err(|e| crate::DaemonError::Config(e.to_string()))
    }

    pub fn save_to(&self, path: &std::path::Path) -> crate::DaemonResult<()> {
        let text = toml::to_string_pretty(self)
            .map_err(|e| crate::DaemonError::Config(e.to_string()))?;
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        std::fs::write(path, text)?;
        Ok(())
    }
}
```

- [ ] **Step 3: Implement `identity_store.rs`**

This uses `cli_pocket_shared_crypto::Identity` from Plan B which already handles the 0o600 check on Unix during `load_strict`. Daemon-side identity adds a `host_id` derived from the public key.

```rust
use std::path::Path;

use cli_pocket_shared_crypto::Identity;
use cli_pocket_shared_proto::ids::HostId;

#[derive(Debug, Clone)]
pub struct DaemonIdentity {
    pub host_id: HostId,
    pub keypair: cli_pocket_shared_crypto::KeyPair,
}

pub fn load_or_create(path: &Path) -> crate::DaemonResult<DaemonIdentity> {
    let identity = if path.exists() {
        Identity::load_strict(path).map_err(|e| crate::DaemonError::Identity(e.to_string()))?
    } else {
        let identity = Identity::generate();
        identity
            .save(path)
            .map_err(|e| crate::DaemonError::Identity(e.to_string()))?;
        identity
    };
    let host_id = HostId::from_public_key(identity.keypair.public.as_bytes());
    Ok(DaemonIdentity {
        host_id,
        keypair: identity.keypair,
    })
}
```

- [ ] **Step 3: Implement `client_db.rs`**

```rust
use std::collections::{HashMap, HashSet};
use std::path::{Path, PathBuf};
use std::sync::Arc;

use notify::{Config, Event, RecommendedWatcher, RecursiveMode, Watcher};
use parking_lot::RwLock;
use serde::{Deserialize, Serialize};
use tokio::sync::watch;

use cli_pocket_shared_proto::ids::ClientId;

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ClientRecord {
    pub client_id: ClientId,
    #[serde(with = "hex_serde")]
    pub public_key: [u8; 32],
    pub label: String,
    pub paired_at: u64,
}

#[derive(Default, Serialize, Deserialize)]
struct ClientsFile {
    clients: Vec<ClientRecord>,
}

#[derive(Default, Serialize, Deserialize)]
struct RevokedFile {
    revoked: Vec<ClientId>,
}

mod hex_serde {
    use serde::{Deserialize, Deserializer, Serializer};
    pub fn serialize<S: Serializer>(b: &[u8; 32], s: S) -> Result<S::Ok, S::Error> {
        s.serialize_str(&hex::encode(b))
    }
    pub fn deserialize<'de, D: Deserializer<'de>>(d: D) -> Result<[u8; 32], D::Error> {
        let s = String::deserialize(d)?;
        let v = hex::decode(&s).map_err(serde::de::Error::custom)?;
        v.as_slice()
            .try_into()
            .map_err(|_| serde::de::Error::custom("expected 32 bytes"))
    }
}

struct Inner {
    clients_path: PathBuf,
    revoked_path: PathBuf,
    by_public: HashMap<[u8; 32], ClientRecord>,
    by_id: HashMap<ClientId, ClientRecord>,
    revoked: HashSet<ClientId>,
}

pub struct ClientDb {
    inner: Arc<RwLock<Inner>>,
    rev_tx: watch::Sender<u64>,
    _watcher: RecommendedWatcher,
}

impl ClientDb {
    pub async fn open(clients_path: &Path, revoked_path: &Path) -> crate::DaemonResult<Self> {
        let inner = Inner::load(clients_path, revoked_path)?;
        let inner = Arc::new(RwLock::new(inner));
        let (rev_tx, _rev_rx) = watch::channel(0u64);

        let inner_w = Arc::clone(&inner);
        let rev_tx_w = rev_tx.clone();
        let clients_p = clients_path.to_path_buf();
        let revoked_p = revoked_path.to_path_buf();
        let mut watcher: RecommendedWatcher = notify::recommended_watcher(
            move |res: Result<Event, notify::Error>| {
                if res.is_err() {
                    return;
                }
                if let Ok(new_inner) = Inner::load(&clients_p, &revoked_p) {
                    let mut w = inner_w.write();
                    let was_revoked_count = w.revoked.len();
                    *w = new_inner;
                    let now_revoked_count = w.revoked.len();
                    if now_revoked_count != was_revoked_count {
                        let _ = rev_tx_w.send_modify(|v| *v = v.wrapping_add(1));
                    }
                }
            },
        )
        .map_err(|e| crate::DaemonError::ClientDb(e.to_string()))?;
        watcher
            .configure(Config::default().with_poll_interval(std::time::Duration::from_millis(500)))
            .ok();
        // Watch parent dirs (files may not exist yet).
        if let Some(p) = clients_path.parent() {
            let _ = watcher.watch(p, RecursiveMode::NonRecursive);
        }
        if let Some(p) = revoked_path.parent() {
            if revoked_path.parent() != clients_path.parent() {
                let _ = watcher.watch(p, RecursiveMode::NonRecursive);
            }
        }
        Ok(Self {
            inner,
            rev_tx,
            _watcher: watcher,
        })
    }

    pub async fn add(&self, rec: ClientRecord) -> crate::DaemonResult<()> {
        {
            let mut w = self.inner.write();
            w.by_public.insert(rec.public_key, rec.clone());
            w.by_id.insert(rec.client_id, rec.clone());
        }
        self.persist_clients().await
    }

    pub async fn revoke(&self, cid: ClientId) -> crate::DaemonResult<()> {
        {
            let mut w = self.inner.write();
            w.revoked.insert(cid);
        }
        self.persist_revoked().await?;
        let _ = self.rev_tx.send_modify(|v| *v = v.wrapping_add(1));
        Ok(())
    }

async fn write_atomic(path: &Path, bytes: &[u8]) -> crate::DaemonResult<()> {
    if let Some(parent) = path.parent() {
        tokio::fs::create_dir_all(parent).await?;
    }
    let tmp = path.with_extension("tmp");
    tokio::fs::write(&tmp, bytes).await?;
    tokio::fs::rename(&tmp, path).await?;
    Ok(())
}

    fn load(clients_path: &Path, revoked_path: &Path) -> crate::DaemonResult<Self> {
        let clients = read_or_empty::<ClientsFile>(clients_path)?;
        let revoked = read_or_empty::<RevokedFile>(revoked_path)?;
        let mut by_public = HashMap::new();
        let mut by_id = HashMap::new();

            by_public.insert(r.public_key, r.clone());
            by_id.insert(r.client_id, r);
        }
        Ok(Self {
            clients_path: clients_path.to_path_buf(),
            revoked_path: revoked_path.to_path_buf(),
            by_public,
            by_id,
            revoked: revoked.revoked.into_iter().collect(),
        })
    }
}

}
```

```rust
use cli_pocket_shared_proto::ids::{ClientId, TerminalId};
use hmac::{Hmac, Mac};
use sha2::Sha256;
use subtle::ConstantTimeEq;

const VERSION: u8 = 1;
const TAG_LEN: usize = 16;
const BODY_LEN: usize = 1 + 16 + 16 + 8 + 8;
const TOKEN_LEN: usize = BODY_LEN + TAG_LEN;

type HmacSha256 = Hmac<Sha256>;

pub struct ResumeTokenSecret([u8; 32]);

#[derive(Debug, Clone)]
pub struct ResumeTokenBytes {
    pub bytes: Vec<u8>,
}

#[derive(Debug, Clone)]
pub struct VerifiedResume {
    pub client_id: ClientId,
    pub terminal_id: TerminalId,
    pub issued_ms: u64,
    pub expiry_ms: u64,
}

#[derive(Debug, thiserror::Error)]
pub enum ResumeError {
    #[error("malformed")]
    Malformed,
    #[error("version")]
    BadVersion,
    #[error("expired")]
    Expired,
    #[error("bad tag")]
    BadTag,
}

impl ResumeTokenSecret {
    pub fn from_bytes(b: [u8; 32]) -> Self { Self(b) }

    pub fn mint(
        &self,
        client: &ClientId,
        terminal: &TerminalId,
        now_ms: u64,
        ttl_ms: u64,
    ) -> ResumeTokenBytes {
        let mut body = Vec::with_capacity(BODY_LEN);
        body.push(VERSION);
        body.extend_from_slice(client.as_bytes());
        body.extend_from_slice(terminal.as_bytes());
        body.extend_from_slice(&now_ms.to_be_bytes());
        body.extend_from_slice(&(now_ms + ttl_ms).to_be_bytes());

        let mut mac = HmacSha256::new_from_slice(&self.0).expect("HMAC accepts any length");
        mac.update(&body);
        let tag = mac.finalize().into_bytes();
        body.extend_from_slice(&tag[..TAG_LEN]);
        ResumeTokenBytes { bytes: body }
    }

    pub fn verify(
        &self,
        token: &ResumeTokenBytes,
        now_ms: u64,
    ) -> Result<VerifiedResume, ResumeError> {
        if token.bytes.len() != TOKEN_LEN {
            return Err(ResumeError::Malformed);
        }
        let (body, tag) = token.bytes.split_at(BODY_LEN);
        if body[0] != VERSION {
            return Err(ResumeError::BadVersion);
        }
        let mut mac = HmacSha256::new_from_slice(&self.0).unwrap();
        mac.update(body);
        let expected = mac.finalize().into_bytes();
        if !bool::from(expected[..TAG_LEN].ct_eq(tag)) {
            return Err(ResumeError::BadTag);
        }
        let cid_bytes: [u8; 16] = body[1..17].try_into().unwrap();
        let tid_bytes: [u8; 16] = body[17..33].try_into().unwrap();
        let issued_ms = u64::from_be_bytes(body[33..41].try_into().unwrap());
        let expiry_ms = u64::from_be_bytes(body[41..49].try_into().unwrap());
        if now_ms >= expiry_ms {
            return Err(ResumeError::Expired);
        }
        Ok(VerifiedResume {
            client_id: ClientId::from_bytes(cid_bytes),
            terminal_id: TerminalId::from_bytes(tid_bytes),
            issued_ms,
            expiry_ms,
        })
    }
}
```

```rust
use std::collections::HashMap;
use std::sync::Arc;

use parking_lot::Mutex;
use tokio::task::JoinHandle;

use cli_pocket_server_pty::{Terminal, TerminalBuilder};
use cli_pocket_shared_proto::frame::{KillSignal, TerminalCreateParams, TerminalInfo};
use cli_pocket_shared_proto::ids::TerminalId;

pub struct SessionManager {
    inner: Arc<Mutex<Inner>>,
    config: SessionConfig,
    _reaper: JoinHandle<()>,
}

#[derive(Clone, Copy)]
struct SessionConfig {
    max_terminals: usize,
    scrollback_bytes: usize,
    anchor_interval: usize,
    broadcast_capacity: usize,
}

struct Inner {
    terminals: HashMap<TerminalId, Arc<Terminal>>,
    info: HashMap<TerminalId, TerminalInfo>,
}

impl SessionManager {
    pub fn new(
        max_terminals: usize,
        scrollback_bytes: usize,
        anchor_interval: usize,
        broadcast_capacity: usize,
    ) -> Self {
        let config = SessionConfig {
            max_terminals,
            scrollback_bytes,
            anchor_interval,
            broadcast_capacity,
        };
        let inner = Arc::new(Mutex::new(Inner {
            terminals: HashMap::new(),
            info: HashMap::new(),
        }));
        let reaper_inner = Arc::clone(&inner);
        let reaper = tokio::spawn(async move {
            loop {
                tokio::time::sleep(std::time::Duration::from_millis(100)).await;
                let dead: Vec<TerminalId> = {
                    let g = reaper_inner.lock();
                    g.terminals
                        .iter()
                        .filter_map(|(id, t)| if t.has_exited() { Some(*id) } else { None })
                        .collect()
                };
                if !dead.is_empty() {
                    let mut g = reaper_inner.lock();
                    for id in dead {
                        g.terminals.remove(&id);
                        g.info.remove(&id);
                    }
                }
            }
        });
        Self { inner, config, _reaper: reaper }
    }

    pub async fn create(
        &self,
        params: TerminalCreateParams,
    ) -> crate::DaemonResult<TerminalInfo> {
        {
            let g = self.inner.lock();
            if g.terminals.len() >= self.config.max_terminals {
                return Err(crate::DaemonError::Internal(format!(
                    "terminal limit reached ({})",
                    self.config.max_terminals
                )));
            }
        }
        let mut b = TerminalBuilder::new();
        b.cols(params.cols)
            .rows(params.rows)
            .scrollback_bytes(self.config.scrollback_bytes)
            .anchor_interval(self.config.anchor_interval)
            .broadcast_capacity(self.config.broadcast_capacity);
        if let Some(cwd) = &params.cwd {
            b.cwd(cwd);
        }
        for (k, v) in &params.env {
            b.env(k, v);
        }
        if let Some(shell) = &params.shell {
            b.shell(shell);
        }
        let term = b.spawn()?;
        let info = term.info();
        let id = info.terminal_id;
        let term_arc = Arc::new(term);
        {
            let mut g = self.inner.lock();
            g.terminals.insert(id, term_arc);
            g.info.insert(id, info.clone());
        }
        Ok(info)
    }

    pub async fn attach(&self, id: &TerminalId) -> Option<Arc<Terminal>> {
        self.inner.lock().terminals.get(id).cloned()
    }

    pub async fn kill(&self, id: &TerminalId, sig: KillSignal) -> crate::DaemonResult<()> {
        let term = self
            .inner
            .lock()
            .terminals
            .get(id)
            .cloned()
            .ok_or_else(|| crate::DaemonError::Internal(format!("unknown terminal {id:?}")))?;
        term.kill(sig)?;
        Ok(())
    }

    pub async fn list(&self) -> Vec<TerminalInfo> {
        self.inner.lock().info.values().cloned().collect()
    }

    pub fn count(&self) -> usize {
        self.inner.lock().terminals.len()
    }
}
```

## Task D7: Noise XK Responder Driver

**Files:**
- Modify: `crates/server/daemon-core/src/handshake.rs`

The handshake driver wraps `cli_pocket_shared_crypto::NoiseResponder`. It reads three handshake frames over the transport (per XK pattern: `->e, <-e,ee,s,es, ->s,se`), looks up the client static key in `ClientDb`, and emits a `NoiseSession` for the per-connection frame loop.

- [ ] **Step 1: Implement `handshake.rs`**

```rust
use std::sync::Arc;

use cli_pocket_shared_crypto::{NoiseResponder, NoiseSession};
use cli_pocket_shared_transport::Transport;

use crate::client_db::{ClientDb, ClientRecord};

pub struct AcceptedHandshake {
    pub session: NoiseSession,
    pub client: ClientRecord,
}

pub async fn responder_handshake<T: Transport + ?Sized>(
    transport: &mut T,
    static_priv: &[u8; 32],
    psk: Option<&[u8; 32]>,
    db: &ClientDb,
) -> crate::DaemonResult<AcceptedHandshake> {
    let mut responder = NoiseResponder::new(static_priv, psk)
        .map_err(crate::DaemonError::Crypto)?;

    // <- e
    let msg1 = transport.recv().await?;
    let _ = responder.read_message(&msg1)?;

    // -> e, ee, s, es
    let mut msg2 = vec![0u8; 1024];
    let n = responder.write_message(&[], &mut msg2)?;
    msg2.truncate(n);
    transport.send(&msg2).await?;

    // <- s, se
    let msg3 = transport.recv().await?;
    let _ = responder.read_message(&msg3)?;

    let session = responder.into_transport()?;
    let client_pk = session
        .remote_static()
        .ok_or_else(|| crate::DaemonError::Internal("missing remote static after XK".into()))?;
    let record = db
        .lookup_by_public(&client_pk)
        .await?
        .ok_or_else(|| crate::DaemonError::NotPaired(hex::encode(client_pk)))?;
    if db.is_revoked(&record.client_id).await {
        return Err(crate::DaemonError::Revoked(record.client_id.to_string()));
    }
    Ok(AcceptedHandshake { session, client: record })
}
```

## Task D8: Per-Connection State Machine

**Files:**
- Modify: `crates/server/daemon-core/src/connection.rs`

The connection task:
1. Runs `responder_handshake` to authenticate the client.
2. Wraps the transport in an encrypted `NoiseSession` framing (encrypt outbound `Frame`, decrypt inbound).
3. Reads the first frame, which must be `FrameBody::Hello`. Returns `HelloOk` with capabilities and (if `resume_token` was set) re-validates.
4. Loops over inbound frames, dispatching:
   - `TerminalCreate` → `SessionManager::create` → `TerminalInfo` reply, then immediately attach.
   - `TerminalAttach { terminal_id, resume_token }` → resolve, optionally re-validate.
   - `TerminalDetach` → drop the subscription.
   - `TerminalKill` → forward to the session manager.
   - `TerminalList` → reply.
   - `Input { bytes }` → `Terminal::write_input`.
   - `Resize { cols, rows }` → `Terminal::resize`.
   - `Window { credits }` → flow control (advance permitted byte counter).
5. For each attached terminal, spawn a writer task that pulls output via `Terminal::subscribe()` and `Terminal::since()` to fill any gap, then forwards `FrameBody::Output { stream_seq, bytes }` to the client through the session.
6. On revocation watch fire (from `ClientDb`), if the connection's client_id is now in the revoked set, send `Bye { reason: Revoked }` and close.

- [ ] **Step 1: Implement `connection.rs`**

```rust
use std::sync::Arc;
use std::time::SystemTime;

use bytes::Bytes;
use cli_pocket_shared_crypto::NoiseSession;
use cli_pocket_shared_proto::codec::{decode_frame, encode_frame};
use cli_pocket_shared_proto::frame::{
    ByeReason, Capabilities, ClientKind, Frame, FrameBody, HelloOk,
    KillSignal, OutputChunk, ResumeAttachment, ServerInfo,
};
use cli_pocket_shared_proto::ids::{ClientId, SessionId, StreamSeq, TerminalId};
use cli_pocket_shared_transport::Transport;
use tokio::sync::mpsc;
use tokio::task::JoinSet;
use tracing::{debug, info, warn};

use crate::client_db::{ClientDb, ClientRecord};
use crate::resume::ResumeTokenSecret;
use crate::session::SessionManager;

pub struct ConnectionDeps {
    pub session_mgr: Arc<SessionManager>,
    pub client_db: Arc<ClientDb>,
    pub resume_secret: Arc<ResumeTokenSecret>,
    pub server_info: ServerInfo,
    pub resume_ttl_ms: u64,
}

/// Wraps a transport and a Noise session for application-layer framing.
struct EncryptedChannel<T: Transport> {
    transport: T,
    session: NoiseSession,
}

impl<T: Transport> EncryptedChannel<T> {
    async fn send_frame(&mut self, frame: &Frame) -> crate::DaemonResult<()> {
        let plain = encode_frame(frame)?;
        let mut ct = vec![0u8; plain.len() + 32];
        let n = self.session.write_message(&plain, &mut ct)?;
        ct.truncate(n);
        self.transport.send(&ct).await?;
        Ok(())
    }

    async fn recv_frame(&mut self) -> crate::DaemonResult<Frame> {
        let ct = self.transport.recv().await?;
        let mut plain = vec![0u8; ct.len()];
        let n = self.session.read_message(&ct, &mut plain)?;
        plain.truncate(n);
        Ok(decode_frame(&plain)?)
    }
}

pub async fn run_connection<T: Transport + Send>(
    mut transport: T,
    deps: ConnectionDeps,
) -> crate::DaemonResult<()> {
    // 1. Handshake
    let identity_priv = deps.server_info.identity_priv_for_handshake;
    let psk_opt = deps.server_info.psk_for_handshake.as_ref();
    let accepted = crate::handshake::responder_handshake(
        &mut transport,
        &identity_priv,
        psk_opt,
        &deps.client_db,
    )
    .await?;
    let client = accepted.client;
    info!(client_id=%client.client_id, "client authenticated");

    let mut chan = EncryptedChannel {
        transport,
        session: accepted.session,
    };

    // 2. Wait for Hello
    let hello = chan.recv_frame().await?;
    let (resume_attach, client_kind) = match &hello.body {
        FrameBody::Hello { client_kind, capabilities: _, resume_token } => {
            let resume_attach = if let Some(tok) = resume_token {
                match deps.resume_secret.verify(tok, now_ms()) {
                    Ok(v) if v.client_id == client.client_id => Some(v),
                    _ => None,
                }
            } else {
                None
            };
            (resume_attach, *client_kind)
        }
        _ => {
            chan.send_frame(&Frame::body(FrameBody::Bye {
                reason: ByeReason::Protocol,
                message: "expected Hello".into(),
            }))
            .await?;
            return Err(crate::DaemonError::Internal("expected Hello".into()));
        }
    };

    let session_id = SessionId::new_v7();
    chan.send_frame(&Frame::body(FrameBody::HelloOk(HelloOk {
        session_id,
        server: deps.server_info.public_summary(),
        capabilities: Capabilities::default_v1(),
        resume_attached: resume_attach.as_ref().map(|v| ResumeAttachment {
            terminal_id: v.terminal_id,
        }),
    })))
    .await?;

    // 3. Optional auto-attach if resume succeeded.
    let mut attached: Option<(TerminalId, tokio::task::JoinHandle<()>, mpsc::Sender<()>)> = None;
    if let Some(v) = &resume_attach {
        if let Some(term) = deps.session_mgr.attach(&v.terminal_id).await {
            attached = Some(spawn_terminal_pump(
                v.terminal_id,
                term,
                outbound_tx_for(&mut chan),
            ));
        }
    }

    // 4. Watch for revocation
    let mut rev_rx = deps.client_db.watch_revocations();
    let client_id = client.client_id;

    // 5. Main loop
    loop {
        tokio::select! {
            biased;
            _ = rev_rx.changed() => {
                if deps.client_db.is_revoked(&client_id).await {
                    let _ = chan.send_frame(&Frame::body(FrameBody::Bye {
                        reason: ByeReason::Revoked,
                        message: "client revoked".into(),
                    })).await;
                    return Err(crate::DaemonError::Revoked(client_id.to_string()));
                }
            }
            frame = chan.recv_frame() => {
                let frame = frame?;
                if !handle_frame(frame, &mut chan, &deps, &client, &mut attached).await? {
                    return Ok(());
                }
            }
        }
    }
}

async fn handle_frame<T: Transport + Send>(
    frame: Frame,
    chan: &mut EncryptedChannel<T>,
    deps: &ConnectionDeps,
    client: &ClientRecord,
    attached: &mut Option<(TerminalId, tokio::task::JoinHandle<()>, mpsc::Sender<()>)>,
) -> crate::DaemonResult<bool> {
    match frame.body {
        FrameBody::TerminalCreate(params) => {
            let info = deps.session_mgr.create(params).await?;
            let token = deps.resume_secret.mint(
                &client.client_id,
                &info.terminal_id,
                now_ms(),
                deps.resume_ttl_ms,
            );
            chan.send_frame(&Frame::body(FrameBody::TerminalInfo {
                info: info.clone(),
                resume_token: Some(token),
            }))
            .await?;
            if let Some(term) = deps.session_mgr.attach(&info.terminal_id).await {
                *attached = Some(spawn_terminal_pump(info.terminal_id, term, outbound_tx_for(chan)));
            }
        }
        FrameBody::TerminalAttach { terminal_id, .. } => {
            if let Some(term) = deps.session_mgr.attach(&terminal_id).await {
                *attached = Some(spawn_terminal_pump(terminal_id, term, outbound_tx_for(chan)));
                chan.send_frame(&Frame::body(FrameBody::TerminalAttachOk { terminal_id }))
                    .await?;
            } else {
                chan.send_frame(&Frame::body(FrameBody::TerminalAttachErr {
                    terminal_id,
                    message: "unknown terminal".into(),
                }))
                .await?;
            }
        }
        FrameBody::TerminalDetach { terminal_id: _ } => {
            if let Some((_, handle, stop)) = attached.take() {
                let _ = stop.send(()).await;
                handle.abort();
            }
        }
        FrameBody::TerminalKill { terminal_id, signal } => {
            deps.session_mgr.kill(&terminal_id, signal).await?;
        }
        FrameBody::TerminalList => {
            let list = deps.session_mgr.list().await;
            chan.send_frame(&Frame::body(FrameBody::TerminalListOk { terminals: list }))
                .await?;
        }
        FrameBody::Input { terminal_id, bytes } => {
            if let Some(term) = deps.session_mgr.attach(&terminal_id).await {
                let _ = term.write_input(&bytes);
            }
        }
        FrameBody::Resize { terminal_id, cols, rows } => {
            if let Some(term) = deps.session_mgr.attach(&terminal_id).await {
                let _ = term.resize(cols, rows);
            }
        }
        FrameBody::Window { .. } => {
            // Flow control handled inside spawn_terminal_pump (Plan F drives credits).
        }
        FrameBody::Bye { .. } => {
            return Ok(false);
        }
        FrameBody::Hello { .. }
        | FrameBody::HelloOk(_)
        | FrameBody::HelloErr { .. }
        | FrameBody::TerminalInfo { .. }
        | FrameBody::TerminalAttachOk { .. }
        | FrameBody::TerminalAttachErr { .. }
        | FrameBody::TerminalListOk { .. }
        | FrameBody::Output { .. }
        | FrameBody::Exit { .. } => {
            warn!("client sent server-side frame variant; ignoring");
        }
    }
    Ok(true)
}

/// Pump terminal output into the encrypted channel via a bounded mpsc.
/// We use a small adapter because `EncryptedChannel` is not Sync.
fn spawn_terminal_pump<T: Transport + Send>(
    terminal_id: TerminalId,
    term: Arc<cli_pocket_server_pty::Terminal>,
    outbound: mpsc::Sender<Frame>,
) -> (TerminalId, tokio::task::JoinHandle<()>, mpsc::Sender<()>) {
    let (stop_tx, mut stop_rx) = mpsc::channel::<()>(1);
    let handle = tokio::spawn(async move {
        let mut rx = term.subscribe();
        loop {
            tokio::select! {
                biased;
                _ = stop_rx.recv() => break,
                next = rx.recv() => {
                    match next {
                        cli_pocket_server_pty::OutputRecv::Chunk(seq, bytes) => {
                            let _ = outbound.send(Frame::body(FrameBody::Output {
                                terminal_id,
                                stream_seq: seq,
                                bytes,
                            })).await;
                        }
                        cli_pocket_server_pty::OutputRecv::Lagged { last_seq } => {
                            // Catch up via since() — send one large batched Output.
                            if let Some(delta) = term.since(last_seq) {
                                let _ = outbound.send(Frame::body(FrameBody::Output {
                                    terminal_id,
                                    stream_seq: delta.head_seq,
                                    bytes: Bytes::from(delta.bytes),
                                })).await;
                            }
                        }
                        cli_pocket_server_pty::OutputRecv::Exit(info) => {
                            let _ = outbound.send(Frame::body(FrameBody::Exit {
                                terminal_id,
                                info,
                            })).await;
                            break;
                        }
                    }
                }
            }
        }
    });
    (terminal_id, handle, stop_tx)
}

// Helper to expose chan.send_frame as an mpsc to the pump task — the channel must be
// owned by a single task because EncryptedChannel is not Sync. We use a write-task.
fn outbound_tx_for<T: Transport + Send>(_chan: &mut EncryptedChannel<T>) -> mpsc::Sender<Frame> {
    // In practice the connection runner builds the outbound mpsc + writer task and
    // hands the Sender into spawn_terminal_pump. This helper is a placeholder so
    // this file shows the architectural intent — at integration time wire the
    // outbound writer in `run_connection` instead of using this stub.
    let (tx, _rx) = mpsc::channel(64);
    tx
}

fn now_ms() -> u64 {
    SystemTime::now()
        .duration_since(SystemTime::UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0)
}
```

> Implementation note for the engineer: the `outbound_tx_for` helper above is a placeholder demonstrating the architectural split. In your actual implementation, `run_connection` should spawn a dedicated **writer task** that owns `EncryptedChannel` for writes; reads happen in the main loop. Pass the writer's `mpsc::Sender<Frame>` into `spawn_terminal_pump`. This is a small refactor of the skeleton above — keep the structure, replace the placeholder.

```rust
pub async fn listen(
    addr: SocketAddr,
    deps_factory: Arc<dyn Fn() -> ConnectionDeps + Send + Sync>,
) -> crate::DaemonResult<()> {
    let listener = TcpListener::bind(addr).await?;
    info!(%addr, "daemon listening");
    loop {
        let (sock, peer) = listener.accept().await?;
        let deps = (deps_factory)();
        tokio::spawn(async move {
            info!(%peer, "connection opened");
            let ws = match accept_async(sock).await {
                Ok(ws) => ws,
                Err(e) => {
                    error!(%peer, error=%e, "ws upgrade failed");
                    return;
                }
            };
            let transport = TokioWsTransport::server(ws);
            if let Err(e) = run_connection(transport, deps).await {
                error!(%peer, error=%e, "connection ended with error");
            } else {
                info!(%peer, "connection closed cleanly");
            }
        });
    }
}
```

```rust
use cli_pocket_shared_proto::frame::ServerInfo;
use tokio::task::JoinHandle;

use crate::client_db::ClientDb;

        let identity = load_or_create(&config.security.identity_path)?;
        let client_db = Arc::new(
            ClientDb::open(&config.security.clients_path, &config.security.revoked_path).await?,
        );

        ));

        Ok(Self {
            identity,
            session_mgr,
            client_db,
            resume_secret,
            server_info,
            config,
            listener_handle: None,
            relay_handle: None,
        })
    }

    pub async fn start(&mut self) -> crate::DaemonResult<()> {
        let addr = std::net::SocketAddr::new(self.config.listen.addr, self.config.listen.port);
        let session_mgr = Arc::clone(&self.session_mgr);
        let client_db = Arc::clone(&self.client_db);
        let resume_secret = Arc::clone(&self.resume_secret);
        let server_info = self.server_info.clone();
        let resume_ttl_ms = 7 * 24 * 60 * 60 * 1000;
        let deps_factory: Arc<dyn Fn() -> ConnectionDeps + Send + Sync> =
            Arc::new(move || ConnectionDeps {
                session_mgr: Arc::clone(&session_mgr),
                client_db: Arc::clone(&client_db),
                resume_secret: Arc::clone(&resume_secret),
                server_info: server_info.clone(),
                resume_ttl_ms,
            });
        let handle = tokio::spawn(async move {
            if let Err(e) = crate::listener::listen(addr, deps_factory).await {
                tracing::error!(error=%e, "listener exited");
            }
        });
        self.listener_handle = Some(handle);

        if let Some(relay) = self.config.relay.clone() {
            let host_id = self.identity.host_id;
            let identity = self.identity.keypair.clone();
            let handle = tokio::spawn(async move {
                if let Err(e) = crate::relay_dialer::run(relay, host_id, identity).await {
                    tracing::error!(error=%e, "relay dialer exited");
                }
            });
            self.relay_handle = Some(handle);
        }

        Ok(())
    }

    pub async fn shutdown(self) {
        if let Some(h) = self.listener_handle {
            h.abort();
        }
        if let Some(h) = self.relay_handle {
            h.abort();
        }
    }
}
```

## Task D13: Pairing Subcommand (Daemon Side)

**Files:**

- Modify: `crates/server/daemon-core/src/server.rs` — add `Daemon::run_pairing(code, label)` method

The daemon's pairing flow:
1. Operator runs `cli-pocket-daemon pair`. The daemon prints a 6-digit code (or accepts one from the CLI for scripted use).
2. A short-lived listener on a separate port accepts ONE inbound connection.
3. That connection runs SPAKE2 with the 6-digit code as the shared password.
4. On success, daemon and client both confirm and the client's static public key is appended to `clients.json` with the supplied label.
5. The listener exits.

```rust
pub async fn run_pairing(
    &self,
    code: String,
    label: String,
    bind: std::net::SocketAddr,
) -> crate::DaemonResult<crate::client_db::ClientRecord> {
    use cli_pocket_shared_crypto::Spake2Side;
    use cli_pocket_shared_proto::ids::ClientId;
    use cli_pocket_shared_transport::TokioWsTransport;
    use tokio::net::TcpListener;
    use tokio_tungstenite::accept_async;

    let listener = TcpListener::bind(bind).await?;
    tracing::info!(addr=%bind, "pairing listener up; code = {code}");
    let (sock, _peer) = listener.accept().await?;
    let ws = accept_async(sock).await.map_err(|e| {
        crate::DaemonError::Internal(format!("ws upgrade during pairing: {e}"))
    })?;
    let mut t = TokioWsTransport::server(ws);

    // SPAKE2 — server side.
    let (mut sp, send_msg) = Spake2Side::server(code.as_bytes());
    t.send(&send_msg).await?;
    let peer_msg = t.recv().await?;
    let shared = sp.finish(&peer_msg)
        .map_err(|e| crate::DaemonError::Crypto(e.into()))?;

    // The client now uses `shared` to encrypt their static public key + label hint.
    // We use a simple sealed-box: HKDF(shared, "cli-pocket pairing v1") -> key,
    // then ChaCha20Poly1305 of a 32-byte client public key.
    let payload = t.recv().await?;
    let client_pk: [u8; 32] = decrypt_pairing_payload(&shared, &payload)?
        .as_slice()
        .try_into()
        .map_err(|_| crate::DaemonError::Internal("expected 32-byte client pk".into()))?;

    let record = crate::client_db::ClientRecord {
        client_id: ClientId::new_v7(),
        public_key: client_pk,
        label,
        paired_at: std::time::SystemTime::now()
            .duration_since(std::time::UNIX_EPOCH)
            .map(|d| d.as_secs())
            .unwrap_or(0),
    };
    self.client_db.add(record.clone()).await?;

    // Send confirmation (encrypted host public key for the client to pin).
    let host_pk = self.identity.keypair.public.as_bytes();
    let ack = encrypt_pairing_payload(&shared, host_pk)?;
    t.send(&ack).await?;

    Ok(record)
}

fn decrypt_pairing_payload(shared: &[u8], ct: &[u8]) -> crate::DaemonResult<Vec<u8>> {
    use chacha20poly1305::{aead::Aead, ChaCha20Poly1305, KeyInit};
    let mut key = [0u8; 32];
    cli_pocket_shared_crypto::hkdf_expand(shared, b"cli-pocket pairing v1", &mut key)
        .map_err(crate::DaemonError::Crypto)?;
    let cipher = ChaCha20Poly1305::new((&key).into());
    let nonce = [0u8; 12].into();
    cipher.decrypt(&nonce, ct).map_err(|e| {
        crate::DaemonError::Internal(format!("pairing decrypt failed: {e}"))
    })
}

fn encrypt_pairing_payload(shared: &[u8], plain: &[u8]) -> crate::DaemonResult<Vec<u8>> {
    use chacha20poly1305::{aead::Aead, ChaCha20Poly1305, KeyInit};
    let mut key = [0u8; 32];
    cli_pocket_shared_crypto::hkdf_expand(shared, b"cli-pocket pairing v1", &mut key)
        .map_err(crate::DaemonError::Crypto)?;
    let cipher = ChaCha20Poly1305::new((&key).into());
    let nonce = [0u8; 12].into();
    cipher.encrypt(&nonce, plain).map_err(|e| {
        crate::DaemonError::Internal(format!("pairing encrypt failed: {e}"))
    })
}
```
