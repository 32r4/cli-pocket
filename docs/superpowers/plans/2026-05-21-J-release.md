# Release Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a release pipeline that, on a `v*` git tag push, produces signed and reproducible artifacts for daemon, relay, desktop app, mobile app, web app, and CLIs. Signing uses `minisign` (ADR 0007). No auto-update mechanism in v1 (ADR 0008) — users update by re-downloading. The pipeline is GitHub Actions, but the orchestration is shell-scripted so it can run locally too (`make release-local`).

**Architecture:** A single `release.yml` workflow with one job per target triple. Each job builds the relevant crate / app, signs the output blob with `minisign`, and uploads it to a GitHub Release draft. A final `publish` job verifies all signatures with `minisign -V`, attaches a `SHA256SUMS` file, and flips the release from draft to published. A short `scripts/release/` directory contains the per-target build commands so they are testable outside CI.

**Tech Stack:**
- GitHub Actions (matrix builds on `ubuntu-22.04`, `macos-14`, `windows-2022`).
- `minisign` 0.11+ for signatures (ADR 0007).
- `cargo-deb` 2.x for `.deb`, `cargo-generate-rpm` 0.14 for `.rpm`.
- `tauri-action` 0.5 (current as of May 2026) for desktop installer packaging (`.msi` / `.dmg` / `.AppImage`).
- Android: `tauri android build --apk --aab` (requires Android Studio + NDK in the runner; we use `nektos/act-android` style preinstall steps).
- iOS: `tauri ios build` (macOS runner only; signing requires manual cert setup outside CI for v1 — pipeline produces unsigned `.ipa` artifacts and documents the manual sign step).
- Homebrew: a separate `homebrew-cli-pocket` tap repo (created out of band; this plan only ships the bottle file).

# scripts/release/

Per-target build scripts. Each script:

- Takes `$TARGET` (e.g. `x86_64-unknown-linux-gnu`) and `$VERSION` (semver
  without leading `v`) from the environment.
- Produces one tarball in `dist/` whose name is
  `<artifact>-<version>-<target>.<ext>` (e.g.
  `cli-pocket-daemon-0.1.0-x86_64-unknown-linux-gnu.tar.gz`).
- Exits non-zero on failure.

After all scripts run, `sign.sh dist/` produces a `.minisig` next to each file
and `sha256sums.sh dist/` produces `SHA256SUMS` and `SHA256SUMS.minisig`.

Run locally:

```sh
VERSION=0.1.0 TARGET=x86_64-unknown-linux-gnu bash scripts/release/build-daemon.sh
VERSION=0.1.0 bash scripts/release/sign.sh dist/
```
```

- [ ] **Step 2: `scripts/release/build-daemon.sh`**

```sh
#!/usr/bin/env bash
set -euo pipefail

: "${VERSION:?VERSION env var required}"
: "${TARGET:?TARGET env var required}"

ARTIFACT="cli-pocket-daemon-${VERSION}-${TARGET}"
OUT_DIR="${OUT_DIR:-dist}"
mkdir -p "$OUT_DIR"

cargo build --release --locked --target "$TARGET" -p cli-pocket-daemon

case "$TARGET" in
  *-windows-*)
    BIN_SUFFIX=".exe"
    EXT="zip"
    ;;
  *)
    BIN_SUFFIX=""
    EXT="tar.gz"
    ;;
esac

STAGE="$(mktemp -d)/$ARTIFACT"
mkdir -p "$STAGE"
cp "target/${TARGET}/release/cli-pocket-daemon${BIN_SUFFIX}" "$STAGE/"
cp README.md LICENSE-MIT LICENSE-APACHE "$STAGE/" 2>/dev/null || true
cp docs/release/VERIFY.md "$STAGE/" || true

case "$EXT" in
  tar.gz)
    tar -C "$(dirname "$STAGE")" -czf "$OUT_DIR/${ARTIFACT}.tar.gz" "$(basename "$STAGE")"
    ;;
  zip)
    (cd "$(dirname "$STAGE")" && zip -qr "$OLDPWD/$OUT_DIR/${ARTIFACT}.zip" "$(basename "$STAGE")")
    ;;
esac

echo "Built $OUT_DIR/${ARTIFACT}.${EXT}"
```

## Task J4: `sign.sh` / `verify.sh` / `sha256sums.sh`

**Files:**

- Create: `scripts/release/sha256sums.sh`

- [ ] **Step 1: `sign.sh`**

```sh
#!/usr/bin/env bash
# Sign every file in $1 (default: dist/) with the maintainer's minisign key.
# Requires $MINISIGN_PASSWORD to be set; reads the key from $MINISIGN_KEY_FILE
# (default: ./cli-pocket-minisign.key). In CI the secret is materialised into
# that path by the workflow step that calls this script.
set -euo pipefail
DIR="${1:-dist}"
KEY="${MINISIGN_KEY_FILE:-./cli-pocket-minisign.key}"
: "${MINISIGN_PASSWORD:?MINISIGN_PASSWORD env var required}"

shopt -s nullglob
for f in "$DIR"/*; do
  case "$f" in
    *.minisig|*SHA256SUMS) continue ;;
  esac
  if [ -f "$f" ]; then
    echo "Signing $f"
    echo "$MINISIGN_PASSWORD" | minisign -S -s "$KEY" -m "$f" -t "cli-pocket release"
  fi
done
```

- [ ] **Step 2: `verify.sh`**

```sh
#!/usr/bin/env bash
set -euo pipefail
DIR="${1:-dist}"
PUB="${MINISIGN_PUB_FILE:-./cli-pocket-minisign.pub}"

shopt -s nullglob
fail=0
for sig in "$DIR"/*.minisig; do
  file="${sig%.minisig}"
  if minisign -V -p "$PUB" -m "$file" >/dev/null 2>&1; then
    echo "OK   $file"
  else
    echo "FAIL $file"
    fail=1
  fi
done
exit $fail
```

- [ ] **Step 3: `sha256sums.sh`**

```sh
#!/usr/bin/env bash
set -euo pipefail
DIR="${1:-dist}"
(cd "$DIR" && find . -maxdepth 1 -type f ! -name 'SHA256SUMS*' ! -name '*.minisig' \
  | sort \
  | xargs sha256sum) > "$DIR/SHA256SUMS"
echo "Wrote $DIR/SHA256SUMS"
```

## Task J5: `build-desktop.sh` — Tauri Installers

**Files:**
- Create: `scripts/release/build-desktop.sh`

The script invokes `cargo tauri build` from `apps/desktop/` and copies the resulting installer into `dist/`. It runs once per host OS (we only build the host's installers in a given runner; cross-installer-building is not supported by Tauri).

- [ ] **Step 1: Implement**

```sh
#!/usr/bin/env bash
set -euo pipefail

: "${VERSION:?VERSION env var required}"
OUT_DIR="${OUT_DIR:-dist}"
mkdir -p "$OUT_DIR"

cd webview/terminal
npm ci
npm run build:tauri
cd "$OLDPWD"

cd apps/desktop
cargo tauri build --bundles "${TAURI_BUNDLES:-app,deb,msi,dmg,appimage,rpm}"
cd "$OLDPWD"

TARGET_DIR="apps/desktop/src-tauri/target/release/bundle"

# Collect every produced installer into dist/.
shopt -s globstar nullglob
for f in "$TARGET_DIR"/**/*; do
  case "$f" in
    *.deb|*.rpm|*.AppImage|*.msi|*.dmg|*.app.tar.gz) ;;
    *) continue ;;
  esac
  base="$(basename "$f")"
  cp "$f" "$OUT_DIR/cli-pocket-desktop-${VERSION}-${base}"
done

ls -lh "$OUT_DIR"
```

`tauri build --bundles` accepts a comma-separated list; CI passes only the formats valid for the current runner (`deb,rpm,appimage` on Linux, `msi` on Windows, `dmg,app` on macOS).

**Files:**
- Create: `.github/workflows/release.yml`

- [ ] **Step 1: Implement**

```yaml
name: release

on:
  push:
    tags: ["v*"]
  workflow_dispatch:
    inputs:
      version:
        description: "Version (without leading v)"
        required: true

jobs:
  build:
    name: build (${{ matrix.os }} / ${{ matrix.target }})
    runs-on: ${{ matrix.os }}
    strategy:
      fail-fast: false
      matrix:
        include:
          - os: ubuntu-22.04
            target: x86_64-unknown-linux-gnu
            kinds: "daemon,relay,desktop,web"
          - os: ubuntu-22.04
            target: aarch64-unknown-linux-gnu
            kinds: "daemon,relay"
          - os: macos-14
            target: x86_64-apple-darwin
            kinds: "daemon,relay,desktop"
          - os: macos-14
            target: aarch64-apple-darwin
            kinds: "daemon,relay,desktop,mobile-ios"
          - os: windows-2022
            target: x86_64-pc-windows-msvc
            kinds: "daemon,relay,desktop"
          - os: ubuntu-22.04
            target: android
            kinds: "mobile-android"

    steps:
      - uses: actions/checkout@v4

      - name: Derive VERSION
        id: ver
        shell: bash
        run: |
          if [ "${{ github.event_name }}" = "workflow_dispatch" ]; then
            echo "version=${{ github.event.inputs.version }}" >> "$GITHUB_OUTPUT"
          else
            echo "version=${GITHUB_REF_NAME#v}" >> "$GITHUB_OUTPUT"
          fi

      - uses: dtolnay/rust-toolchain@stable
        with:
          targets: ${{ matrix.target == 'android' && '' || matrix.target }}

      - name: Add cross-linker (linux aarch64)
        if: matrix.target == 'aarch64-unknown-linux-gnu'
        run: |
          sudo apt-get update
          sudo apt-get install -y gcc-aarch64-linux-gnu
          mkdir -p .cargo
          cat >> .cargo/config.toml <<EOF
          [target.aarch64-unknown-linux-gnu]
          linker = "aarch64-linux-gnu-gcc"
          EOF

      - uses: actions/setup-node@v4
        with:
          node-version: 22
        if: contains(matrix.kinds, 'desktop') || contains(matrix.kinds, 'web') || contains(matrix.kinds, 'mobile')

      - name: Install Tauri prerequisites (linux)
        if: runner.os == 'Linux' && (contains(matrix.kinds, 'desktop') || contains(matrix.kinds, 'mobile-android'))
        run: |
          sudo apt-get update
          sudo apt-get install -y libwebkit2gtk-4.1-dev libjavascriptcoregtk-4.1-dev libsoup-3.0-dev libssl-dev pkg-config librsvg2-dev

      - name: Install wasm-pack
        if: contains(matrix.kinds, 'web')
        run: curl https://rustwasm.github.io/wasm-pack/installer/init.sh -sSf | sh

      - name: Install tauri-cli
        if: contains(matrix.kinds, 'desktop') || contains(matrix.kinds, 'mobile-android') || contains(matrix.kinds, 'mobile-ios')
        run: cargo install tauri-cli --version "^2.1" --locked

      - name: Install minisign
        shell: bash
        run: |
          case "${{ runner.os }}" in
            Linux)   sudo apt-get install -y minisign ;;
            macOS)   brew install minisign ;;
            Windows) choco install minisign -y ;;
          esac

      - name: Materialise signing key
        if: secrets.MINISIGN_SECRET_KEY != ''
        shell: bash
        env:
          KEY: ${{ secrets.MINISIGN_SECRET_KEY }}
        run: |
          printf '%s' "$KEY" > cli-pocket-minisign.key
          chmod 600 cli-pocket-minisign.key

      - name: Build daemon
        if: contains(matrix.kinds, 'daemon')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
          TARGET: ${{ matrix.target }}
        shell: bash
        run: bash scripts/release/build-daemon.sh

      - name: Build relay
        if: contains(matrix.kinds, 'relay')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
          TARGET: ${{ matrix.target }}
        shell: bash
        run: bash scripts/release/build-relay.sh

      - name: Build desktop
        if: contains(matrix.kinds, 'desktop')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
          TAURI_BUNDLES: ${{ runner.os == 'Linux' && 'deb,rpm,appimage' || runner.os == 'macOS' && 'dmg,app' || 'msi' }}
        shell: bash
        run: bash scripts/release/build-desktop.sh

      - name: Build web
        if: contains(matrix.kinds, 'web')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
        shell: bash
        run: bash scripts/release/build-web.sh

      - name: Setup Java + Android SDK
        if: contains(matrix.kinds, 'mobile-android')
        uses: actions/setup-java@v4
        with:
          distribution: temurin
          java-version: 17

      - name: Setup Android NDK
        if: contains(matrix.kinds, 'mobile-android')
        uses: nttld/setup-ndk@v1
        with:
          ndk-version: r26d

      - name: Build mobile (android)
        if: contains(matrix.kinds, 'mobile-android')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
        shell: bash
        run: bash scripts/release/build-mobile-android.sh

      - name: Build mobile (ios)
        if: contains(matrix.kinds, 'mobile-ios')
        env:
          VERSION: ${{ steps.ver.outputs.version }}
        shell: bash
        run: bash scripts/release/build-mobile-ios.sh

      - name: Sign artifacts
        if: secrets.MINISIGN_SECRET_KEY != ''
        env:
          MINISIGN_KEY_FILE: cli-pocket-minisign.key
          MINISIGN_PASSWORD: ${{ secrets.MINISIGN_PASSWORD }}
        shell: bash
        run: bash scripts/release/sign.sh dist/

      - name: Upload artifacts
        uses: actions/upload-artifact@v4
        with:
          name: dist-${{ matrix.os }}-${{ matrix.target }}
          path: dist/

  publish:
    name: publish release
    needs: build
    runs-on: ubuntu-22.04
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4

      - name: Download all artifacts
        uses: actions/download-artifact@v4
        with:
          path: aggregated/

      - name: Flatten
        run: |
          mkdir -p dist
          find aggregated -type f -exec cp -n {} dist/ \;
          ls -lh dist/

      - name: Generate SHA256SUMS
        run: bash scripts/release/sha256sums.sh dist/

      - name: Install minisign
        run: sudo apt-get update && sudo apt-get install -y minisign

      - name: Sign SHA256SUMS
        env:
          MINISIGN_KEY_FILE: cli-pocket-minisign.key
          MINISIGN_PASSWORD: ${{ secrets.MINISIGN_PASSWORD }}
          KEY: ${{ secrets.MINISIGN_SECRET_KEY }}
        run: |
          printf '%s' "$KEY" > cli-pocket-minisign.key
          chmod 600 cli-pocket-minisign.key
          echo "$MINISIGN_PASSWORD" | minisign -S -s cli-pocket-minisign.key -m dist/SHA256SUMS -t "cli-pocket release"

      - name: Verify everything
        run: |
          curl -fsSL -o cli-pocket-minisign.pub https://raw.githubusercontent.com/${{ github.repository }}/main/docs/release/PUBLIC_KEY.md \
            && true # cleaning the markdown wrap is done by the next step
          # Extract the inline `untrusted comment: ...\n<base64>` block from the doc.
          awk '/```text/{flag=1;next}/```/{flag=0}flag' cli-pocket-minisign.pub > tmp.pub && mv tmp.pub cli-pocket-minisign.pub
          MINISIGN_PUB_FILE=cli-pocket-minisign.pub bash scripts/release/verify.sh dist/

      - name: Create GitHub Release
        uses: softprops/action-gh-release@v2
        with:
          draft: true
          files: |
            dist/*
          body_path: docs/release/VERIFY.md
```

```markdown
# Releasing cli-pocket

This is a manual process. CI does the heavy lifting (build + sign + draft
release), but a maintainer must approve and publish.

## Prerequisites (one-time)

- The maintainer has access to the GitHub repo `32r4/cli-pocket`.
- GitHub Actions secrets `MINISIGN_SECRET_KEY` and `MINISIGN_PASSWORD` are set.
- Local minisign public key matches `docs/release/PUBLIC_KEY.md`.

## Steps

1. Decide the new version, e.g. `0.2.0`. Follow semver.
2. Update `CHANGELOG.md` (manual; auto-generation is out of scope for v1).
3. Bump versions in:
   - All `crates/**/Cargo.toml` (use `cargo set-version 0.2.0 --workspace`).
   - `apps/desktop/src-tauri/tauri.conf.json`, `apps/mobile/src-tauri/tauri.conf.json`.
   - `apps/web/package.json`, `webview/terminal/package.json`.
4. Commit: `git commit -am "chore: bump to 0.2.0"`.
5. Tag: `git tag -a v0.2.0 -m "v0.2.0"`.
6. Push: `git push && git push --tags`. CI runs the `release` workflow.
7. Watch the workflow; on success it creates a **draft** release with all
   artifacts attached.
8. Download `SHA256SUMS` and `SHA256SUMS.minisig`; verify locally:

   ```
   minisign -V -p cli-pocket-minisign.pub -m SHA256SUMS
   ```

9. Update the Homebrew tap (`32r4/homebrew-cli-pocket`):
   - Take `packaging/homebrew/cli-pocket.rb.template`.
   - Substitute `@VERSION@` and the four `@SHA_*@` values from `SHA256SUMS`.
   - Open a PR against the tap repo.
10. Edit the draft release notes (paste the relevant chunk of `CHANGELOG.md`),
    then **Publish release**.
11. Announce: project README badge auto-tracks the latest release; no other
    announcement system is wired up in v1.

## Rollback

If a release is broken:

1. Click **Delete release** on the GitHub release page.
2. Delete the tag locally: `git tag -d v0.2.0 && git push origin :refs/tags/v0.2.0`.
3. The Homebrew tap PR can be closed (or merged then reverted).
```

## Handoff Notes

**To future maintenance:**
- Apple notarization & Authenticode signing are deferred to a v1.x ticket. The current pipeline emits unsigned macOS `.app`/`.dmg` and Windows `.msi`; users see Gatekeeper / SmartScreen warnings. Document this prominently in the README.
- Auto-update is intentionally absent (ADR 0008). When v2 reconsiders, it should re-use the minisign verification path: ship update manifests signed by the same key.
- The Homebrew tap PR step (J10) is manual in v1. A future improvement is a small "tap-bump" GitHub Action that runs on release publication and opens the PR automatically.
- The aarch64 Linux build cross-compiles from x86_64 Ubuntu; if `ring` or another sys-crate breaks cross-compile in a future version, switch the matrix entry to a `linux-arm64` runner once GitHub offers them at GA pricing.
- iOS signing: for production releases on the App Store, follow Tauri's `tauri ios build --export-method app-store` once a maintainer has an Apple Developer account. Document in `docs/release/IOS_SIGNING.md` when that happens.
