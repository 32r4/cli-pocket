# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a first-class web client (`apps/web/`) that pairs to a daemon **through the relay** (browsers cannot reach a daemon directly without a public LAN), persists identity in IndexedDB, and renders the terminal with the same xterm.js frontend used by the Tauri apps. The web app is a Vite project that bundles `webview/terminal/` with `--mode web` plus the `wasm-pack`-built `cli-pocket-client-core-wasm` package from Plan F.

**Architecture:** A small Vite app at `apps/web/` whose `index.html` mounts Plan G's `App` component, but selects the `WebBridge` (the `?mock=1` short-circuit is preserved). `WebBridge` instantiates a `CliPocketClient` from the wasm package — Plan F left this class as a skeleton (Task F13/F14). This plan **fills in** `connect / next_event / send_input / resize / kill / export_identity / import_identity / close` on that class so it speaks Plan B's wire protocol via `WsTransport` + Noise + `EncryptedChannel`. A pairing UX (6-digit code page) drives SPAKE2 against the daemon over the relay's `/ws/client` route. Identity (Ed25519 + X25519 keys) lives in IndexedDB across reloads; export/import is plain JSON.

**Tech Stack:**
- Vite 5 (web mode), TypeScript strict.
- `cli-pocket-client-core-wasm` (Plan F) — produced by `wasm-pack build --target web`.
- The webview/terminal package from Plan G (already shipped) — consumed as a relative path import.
- Standard browser APIs: `WebSocket`, `IndexedDB`, `crypto.getRandomValues`, `crypto.subtle` (only for fingerprint hashing — Noise/SPAKE2 are inside the wasm).

```rust
use cli_pocket_client_core::{
    ClientEvent, ClientIdentity, ConnectConfig, SessionBuilder, SessionCommand,
    run_session_loop,
};
use crate::{CryptoRng, IdbStore, PerfClock, WsTransport};
use std::cell::RefCell;
use std::rc::Rc;
use tokio::sync::mpsc;
use wasm_bindgen::prelude::*;
use wasm_bindgen_futures::spawn_local;

#[wasm_bindgen]
pub struct CliPocketClient {
    cmd_tx: Rc<RefCell<Option<mpsc::Sender<SessionCommand>>>>,
    event_rx: Rc<RefCell<Option<mpsc::Receiver<ClientEvent>>>>,
    kv: IdbStore,
    rng: CryptoRng,
    clock: PerfClock,
    identity: Rc<RefCell<Option<ClientIdentity>>>,
}

#[wasm_bindgen]
impl CliPocketClient {
    #[wasm_bindgen(constructor)]
    pub fn new() -> Result<CliPocketClient, JsValue> {
        let kv = IdbStore::open()
            .map_err(|e| JsValue::from_str(&format!("IdbStore::open: {e}")))?;
        Ok(CliPocketClient {
            cmd_tx: Rc::new(RefCell::new(None)),
            event_rx: Rc::new(RefCell::new(None)),
            kv,
            rng: CryptoRng,
            clock: PerfClock,
            identity: Rc::new(RefCell::new(None)),
        })
    }

    /// `config` is a plain JS object: `{ endpoint_url, server_public_hex, resume_token_hex? }`.
    #[wasm_bindgen]
    pub async fn connect(&self, config: JsValue) -> Result<(), JsValue> {
        let cfg: ConnectCfgJs = serde_wasm_bindgen::from_value(config)?;

        // Load-or-create identity once per process.
        {
            let mut idg = self.identity.borrow_mut();
            if idg.is_none() {
                let id = ClientIdentity::load_or_create(&self.kv, &self.rng)
                    .await
                    .map_err(|e| JsValue::from_str(&format!("identity: {e}")))?;
                *idg = Some(id);
            }
        }
        let identity = self.identity.borrow().as_ref().unwrap().clone();

        // Open transport.
        let transport = WsTransport::connect(&cfg.endpoint_url, Some("cli-pocket-relay-client/v1"))
            .await
            .map_err(|e| JsValue::from_str(&format!("transport: {e:?}")))?;

        let server_static = hex::decode(&cfg.server_public_hex)
            .map_err(|e| JsValue::from_str(&format!("server_public_hex: {e}")))?;
        let resume_token = match cfg.resume_token_hex.as_deref() {
            Some(s) => Some(hex::decode(s).map_err(|e| JsValue::from_str(&e.to_string()))?),
            None => None,
        };

        let (cmd_tx, cmd_rx) = mpsc::channel(64);
        let (ev_tx, ev_rx) = mpsc::channel(256);

        let builder = SessionBuilder::new(identity)
            .with_clock(self.clock)
            .with_rng(self.rng)
            .with_kv(self.kv.clone());

        let cc = ConnectConfig {
            transport: Box::new(transport),
            server_static_public: server_static,
            resume_token,
        };

        spawn_local(async move {
            run_session_loop(builder, cc, cmd_rx, ev_tx).await;
        });

        *self.cmd_tx.borrow_mut() = Some(cmd_tx);
        *self.event_rx.borrow_mut() = Some(ev_rx);
        Ok(())
    }
}

#[derive(serde::Deserialize)]
struct ConnectCfgJs {
    endpoint_url: String,
    server_public_hex: String,
    #[serde(default)]
    resume_token_hex: Option<String>,
}
```

Ensure `Cargo.toml` for `client-core-wasm` already lists `serde_wasm_bindgen = "0.6"` and `hex = "0.4"` from Plan F; if not, add them.

```rust
#[wasm_bindgen]
pub async fn next_event(&self) -> Result<JsValue, JsValue> {
    let rx_cell = self.event_rx.clone();
    let mut rx = match rx_cell.borrow_mut().take() {
        Some(r) => r,
        None => return Err(JsValue::from_str("no active session")),
    };
    let ev = rx.recv().await;
    *rx_cell.borrow_mut() = Some(rx);
    match ev {
        Some(e) => Ok(serialize_event(&e)),
        None => Err(JsValue::from_str("session ended")),
    }
}

fn serialize_event(ev: &ClientEvent) -> JsValue {
    use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
    use js_sys::{Object, Reflect};
    let obj = Object::new();
    let set = |k: &str, v: JsValue| { Reflect::set(&obj, &JsValue::from_str(k), &v).unwrap(); };
    match ev {
        ClientEvent::Connecting => set("kind", JsValue::from_str("Connecting")),
        ClientEvent::Connected { session_id } => {
            set("kind", JsValue::from_str("Connected"));
            set("session_id", JsValue::from_str(&hex::encode(session_id)));
        }
        ClientEvent::Disconnected { will_retry, reason } => {
            set("kind", JsValue::from_str("Disconnected"));
            set("will_retry", JsValue::from_bool(*will_retry));
            set("reason", JsValue::from_str(reason));
        }
        ClientEvent::TerminalCreated { info } => {
            set("kind", JsValue::from_str("TerminalCreated"));
            let info_obj = Object::new();
            Reflect::set(&info_obj, &"terminal_id".into(), &JsValue::from_str(&hex::encode(&info.terminal_id))).unwrap();
            Reflect::set(&info_obj, &"cols".into(), &JsValue::from_f64(info.cols as f64)).unwrap();
            Reflect::set(&info_obj, &"rows".into(), &JsValue::from_f64(info.rows as f64)).unwrap();
            Reflect::set(&info_obj, &"cwd".into(), &info.cwd.as_deref().map(JsValue::from_str).unwrap_or(JsValue::NULL)).unwrap();
            Reflect::set(&info_obj, &"shell".into(), &JsValue::from_str(&info.shell)).unwrap();
            Reflect::set(&info_obj, &"pid".into(), &info.pid.map(|p| JsValue::from_f64(p as f64)).unwrap_or(JsValue::NULL)).unwrap();
            set("info", info_obj.into());
        }
        ClientEvent::TerminalOutput { terminal_id, stream_seq, bytes } => {
            set("kind", JsValue::from_str("TerminalOutput"));
            set("terminal_id", JsValue::from_str(&hex::encode(terminal_id)));
            set("stream_seq", JsValue::from_f64(*stream_seq as f64));
            set("bytes_b64", JsValue::from_str(&B64.encode(bytes)));
        }
        ClientEvent::TerminalExited { terminal_id, info } => {
            set("kind", JsValue::from_str("TerminalExited"));
            set("terminal_id", JsValue::from_str(&hex::encode(terminal_id)));
            let info_obj = Object::new();
            Reflect::set(&info_obj, &"code".into(), &info.code.map(|c| JsValue::from_f64(c as f64)).unwrap_or(JsValue::NULL)).unwrap();
            Reflect::set(&info_obj, &"signal".into(), &info.signal.as_deref().map(JsValue::from_str).unwrap_or(JsValue::NULL)).unwrap();
            set("info", info_obj.into());
        }
        ClientEvent::Error { message } => {
            set("kind", JsValue::from_str("Error"));
            set("message", JsValue::from_str(message));
        }
    }
    obj.into()
}
```

```rust
    }

    #[wasm_bindgen]
    pub async fn resize(&self, terminal_id: String, cols: u16, rows: u16) -> Result<(), JsValue> {
        let tid = hex::decode(&terminal_id).map_err(|e| JsValue::from_str(&e.to_string()))?;
        self.send_cmd(SessionCommand::Resize { terminal_id: tid, cols, rows }).await
    }

    #[wasm_bindgen]
    pub async fn kill(&self, terminal_id: String, signal: Option<String>) -> Result<(), JsValue> {
        let tid = hex::decode(&terminal_id).map_err(|e| JsValue::from_str(&e.to_string()))?;
        self.send_cmd(SessionCommand::Kill {
            terminal_id: tid,
            signal: signal.unwrap_or_else(|| "TERM".into()),
```

```rust
#[wasm_bindgen]
impl CliPocketClient {
    #[wasm_bindgen]
    pub async fn export_identity(&self) -> Result<String, JsValue> {
        let idg = self.identity.borrow();
        let id = idg.as_ref().ok_or_else(|| JsValue::from_str("no identity loaded"))?;
        let blob = id.export_serialized().map_err(|e| JsValue::from_str(&e.to_string()))?;
        Ok(base64::engine::general_purpose::STANDARD.encode(blob))
    }

    #[wasm_bindgen]
    pub async fn import_identity(&self, blob: String) -> Result<(), JsValue> {
        use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
        let raw = B64.decode(&blob).map_err(|e| JsValue::from_str(&e.to_string()))?;
        let id = ClientIdentity::import_serialized(&raw).map_err(|e| JsValue::from_str(&e.to_string()))?;
        id.persist_to(&self.kv).await.map_err(|e| JsValue::from_str(&e.to_string()))?;
        *self.identity.borrow_mut() = Some(id);
        Ok(())
    }

    #[wasm_bindgen]
    pub async fn close(&self) -> Result<(), JsValue> {
        if let Some(tx) = self.cmd_tx.borrow_mut().take() {
            let _ = tx.send(SessionCommand::Shutdown).await;
        }
        *self.event_rx.borrow_mut() = None;
        Ok(())
    }
}
```

## Task I5: Wasm SPAKE2 Pairing Driver — `client_pair_with_code`

**Files:**
- Create: `crates/client/client-core-wasm/src/pairing.rs`
- Modify: `crates/client/client-core-wasm/src/lib.rs` (add `mod pairing; pub use pairing::*;`)

The host (daemon) is already a SPAKE2 responder (Plan D). The web client needs to drive the SPAKE2 **initiator** side via the relay's `/ws/client?host=<host_pub_hex>` route. On success the client receives the daemon's static public key (32 bytes) and a freshly minted resume token; these are returned to JS so the UI can stash them and call `connect`.

- [ ] **Step 1: Implement `pairing.rs`**

```rust
use crate::WsTransport;
use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
use cli_pocket_shared::pairing::{ClientHelloPair, HostPairOk}; // Plan B frame defs
use cli_pocket_shared::wire::{decode_frame, encode_frame, Frame};
use spake2::{Ed25519Group, Identity, Password, Spake2};
use wasm_bindgen::prelude::*;

#[wasm_bindgen]
pub async fn client_pair_with_code(
    relay_url: String,
    host_pub_hex: String,
    code: String,
) -> Result<JsValue, JsValue> {
    let host_pub = hex::decode(&host_pub_hex)
        .map_err(|e| JsValue::from_str(&format!("host_pub_hex: {e}")))?;
    if host_pub.len() != 32 {
        return Err(JsValue::from_str("host_pub_hex must be 32 bytes"));
    }

    // 1. Open the relay client-side socket.
    let endpoint = format!("{}?host={}", relay_url, host_pub_hex);
    let mut transport = WsTransport::connect(&endpoint, Some("cli-pocket-relay-client/v1"))
        .await
        .map_err(|e| JsValue::from_str(&format!("transport: {e:?}")))?;

    // 2. Drive SPAKE2 (initiator). Identity strings MUST match the daemon's
    //    side (Plan D): id_a = "cli-pocket/spake2/client", id_b = "cli-pocket/spake2/host".
    let pw = Password::new(code.as_bytes());
    let id_a = Identity::new(b"cli-pocket/spake2/client");
    let id_b = Identity::new(b"cli-pocket/spake2/host");
    let (state, msg_a) = Spake2::<Ed25519Group>::start_a(&pw, &id_a, &id_b);

    transport
        .send(encode_frame(&Frame::ClientPairBegin { msg_a: msg_a.clone() }))
        .await
        .map_err(|e| JsValue::from_str(&format!("send msg_a: {e:?}")))?;

    // 3. Wait for HostPairBegin { msg_b, confirmation }.
    let raw = transport.recv().await
        .map_err(|e| JsValue::from_str(&format!("recv msg_b: {e:?}")))?;
    let frame = decode_frame(&raw).map_err(|e| JsValue::from_str(&format!("decode: {e:?}")))?;
    let (msg_b, host_confirm) = match frame {
        Frame::HostPairBegin { msg_b, confirmation } => (msg_b, confirmation),
        f => return Err(JsValue::from_str(&format!("unexpected frame: {f:?}"))),
    };

    let shared = state.finish(&msg_b)
        .map_err(|e| JsValue::from_str(&format!("spake2 finish: {e:?}")))?;

    // 4. Verify host's ChaCha20Poly1305 confirmation; mint our own.
    use chacha20poly1305::{aead::{Aead, KeyInit}, ChaCha20Poly1305, Key, Nonce};
    let key = Key::from_slice(&shared[..32]);
    let cipher = ChaCha20Poly1305::new(key);
    let nonce = Nonce::from_slice(&[0u8; 12]); // single-use key — safe (Plan D notes)

    let host_payload = cipher.decrypt(nonce, host_confirm.as_ref())
        .map_err(|_| JsValue::from_str("host confirmation MAC failed"))?;
    // host_payload = postcard(HostPairOk { server_static_public: [u8;32], resume_token: Vec<u8> })
    let host_ok: HostPairOk = postcard::from_bytes(&host_payload)
        .map_err(|e| JsValue::from_str(&format!("decode host_ok: {e:?}")))?;

    let client_confirm = cipher
        .encrypt(nonce, &b"cli-pocket/spake2/client-ok"[..])
        .map_err(|_| JsValue::from_str("client confirm encrypt"))?;
    transport
        .send(encode_frame(&Frame::ClientPairOk { confirmation: client_confirm }))
        .await
        .map_err(|e| JsValue::from_str(&format!("send client_ok: {e:?}")))?;

    let _ = transport.close().await;

    // 5. Return the unwrapped values to JS.
    let obj = js_sys::Object::new();
    js_sys::Reflect::set(&obj, &"server_public_hex".into(),
        &JsValue::from_str(&hex::encode(host_ok.server_static_public))).unwrap();
    js_sys::Reflect::set(&obj, &"resume_token_hex".into(),
        &JsValue::from_str(&hex::encode(host_ok.resume_token))).unwrap();
    Ok(obj.into())
}
```

Note: `Frame::{ClientPairBegin, HostPairBegin, ClientPairOk}` and the `HostPairOk` postcard struct are introduced in Plan B's pairing wire frames. If Plan B used different variant names, the renames are local to this file.

- [ ] **Step 1: `relayEndpoint.ts`**

```ts
export interface ServerSelector {
  relay_url: string;        // wss://relay.example/ws/client
  host_pub_hex: string;     // 64 hex chars
}

export function pairUrl(s: ServerSelector): string {
  return `${s.relay_url}?host=${s.host_pub_hex}`;
}

export function validateHostPubHex(s: string): string | null {
  const trimmed = s.trim().toLowerCase();
  if (!/^[0-9a-f]{64}$/.test(trimmed)) return "host fingerprint must be 64 hex chars";
  return null;
}

export function validateCode(s: string): string | null {
  if (!/^\d{6}$/.test(s)) return "code must be 6 digits";
  return null;
}
```

- [ ] **Step 2: `PairingView.ts`**

```ts
import { validateCode, validateHostPubHex } from "./relayEndpoint";

export interface PairingValues {
  relay_url: string;
  host_pub_hex: string;
  code: string;
}

export function mountPairingView(parent: HTMLElement, onSubmit: (v: PairingValues) => Promise<void>): void {
  parent.innerHTML = `
    <form class="web-pair-card" novalidate>
      <h1 style="margin:0 0 0.5rem 0;font-size:1.1rem">Pair with a host</h1>
      <label>Relay URL
        <input name="relay_url" placeholder="wss://relay.example.com/ws/client" required>
      </label>
      <label>Host fingerprint (hex)
        <input name="host_pub_hex" placeholder="64 hex characters" required minlength="64" maxlength="64">
      </label>
      <label>6-digit code
        <input name="code" placeholder="000000" inputmode="numeric" pattern="[0-9]{6}" required>
      </label>
      <button type="submit">Pair</button>
      <div class="err" data-role="err" hidden></div>
    </form>
  `;
  const form = parent.querySelector("form")!;
  const errEl = form.querySelector<HTMLElement>('[data-role="err"]')!;

  form.addEventListener("submit", async (e) => {
    e.preventDefault();
    const fd = new FormData(form);
    const v: PairingValues = {
      relay_url: String(fd.get("relay_url") || "").trim(),
      host_pub_hex: String(fd.get("host_pub_hex") || "").trim().toLowerCase(),
      code: String(fd.get("code") || "").trim(),
    };
    const errs = [validateHostPubHex(v.host_pub_hex), validateCode(v.code)].filter(Boolean) as string[];
    if (!v.relay_url) errs.push("relay URL is required");
    if (errs.length) {
      errEl.textContent = errs.join(" · ");
      errEl.hidden = false;
      return;
    }
    errEl.hidden = true;
    (form.querySelector("button")! as HTMLButtonElement).disabled = true;
    try {
      await onSubmit(v);
    } catch (err) {
      errEl.textContent = String(err);
      errEl.hidden = false;
      (form.querySelector("button")! as HTMLButtonElement).disabled = false;
    }
  });
}
```

- [ ] **Step 3: `PairingFlow.ts`**

```ts
import init, { CliPocketClient, client_pair_with_code } from "cli-pocket-client-core-wasm";
import { mountPairingView, PairingValues } from "./PairingView";
import { startApp } from "@terminal/ui/App";
import { WebBridge } from "@terminal/bridge/WebBridge";

const STORE_KEY = "cli-pocket/server-selector/v1";

interface SavedServer {
  endpoint_url: string;     // direct ws URL post-pairing (relay routes are pinned by host_pub_hex)
  server_public_hex: string;
  resume_token_hex: string | null;
}

function loadSaved(): SavedServer | null {
  const raw = localStorage.getItem(STORE_KEY);
  if (!raw) return null;
  try { return JSON.parse(raw) as SavedServer; } catch { return null; }
}

function saveSaved(s: SavedServer): void {
  localStorage.setItem(STORE_KEY, JSON.stringify(s));
}

export async function startWebApp(root: HTMLElement): Promise<void> {
  await init();

  const saved = loadSaved();
  if (saved) {
    await launchTerminal(root, saved);
    return;
  }

  mountPairingView(root, async (v: PairingValues) => {
    // Drive SPAKE2 over the relay.
    const result = await client_pair_with_code(v.relay_url, v.host_pub_hex, v.code) as {
      server_public_hex: string;
      resume_token_hex: string;
    };
    const sel: SavedServer = {
      endpoint_url: `${v.relay_url}?host=${v.host_pub_hex}`,
      server_public_hex: result.server_public_hex,
      resume_token_hex: result.resume_token_hex,
    };
    saveSaved(sel);
    await launchTerminal(root, sel);
  });
}

async function launchTerminal(root: HTMLElement, saved: SavedServer): Promise<void> {
  const client = new CliPocketClient();
  const bridge = new WebBridge(client);
  await bridge.connect({
    endpointUrl: saved.endpoint_url,
    serverPublicHex: saved.server_public_hex,
    resumeTokenHex: saved.resume_token_hex ?? undefined,
  });
  startApp(root, bridge);
}
```

`startApp` is the renderer-mount entrypoint exposed by Plan G's `App.ts`. If Plan G's App exports a default class instead of a function, adjust the import accordingly — the only thing this file needs is "mount xterm.js + status bar + virtual key bar inside `root`, driven by `bridge`."

## Task I8: Identity Export / Import UI

**Files:**
- Create: `apps/web/src/identity/IdentityActions.ts`

Surface "Export identity" and "Import identity" buttons inside the Plan G `StatusBar` slot, or as a small overlay menu. v1 exposes them via two URL hashes (`#export`, `#import`) to keep the renderer UI clean — power users only.

- [ ] **Step 1: Implement**

```ts
import init, { CliPocketClient } from "cli-pocket-client-core-wasm";

let inited = false;
async function ensureInit() {
  if (!inited) { await init(); inited = true; }
}

export async function exportIdentityToFile(client: CliPocketClient): Promise<void> {
  await ensureInit();
  const blob_b64 = await client.export_identity();
  const blob = new Blob([blob_b64], { type: "application/octet-stream" });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = `cli-pocket-identity-${new Date().toISOString().slice(0,10)}.txt`;
  document.body.appendChild(a);
  a.click();
  a.remove();
  URL.revokeObjectURL(url);
}

export async function importIdentityFromPicker(client: CliPocketClient): Promise<void> {
  await ensureInit();
  return new Promise((resolve, reject) => {
    const input = document.createElement("input");
    input.type = "file";
    input.accept = ".txt,application/octet-stream";
    input.onchange = async () => {
      try {
        const f = input.files?.[0];
        if (!f) return resolve();
        const txt = (await f.text()).trim();
        await client.import_identity(txt);
        resolve();
      } catch (e) {
        reject(e);
      }
    };
    input.click();
  });
}

export function installHashHandlers(client: CliPocketClient): void {
  const handler = async () => {
    if (location.hash === "#export") {
      history.replaceState(null, "", location.pathname);
      try { await exportIdentityToFile(client); } catch (e) { alert(`export failed: ${e}`); }
    } else if (location.hash === "#import") {
      history.replaceState(null, "", location.pathname);
      try {
        await importIdentityFromPicker(client);
        location.reload();
      } catch (e) {
        alert(`import failed: ${e}`);
      }
    }
  };
  window.addEventListener("hashchange", handler);
  handler();
}
```

**Files:**

A tiny "cache only the shell" service worker so the app installs on Android Chrome and works offline up to the renderer (the WebSocket itself obviously requires network). Strictly optional for v1 — skip if it complicates Plan J's release pipeline.

- [ ] **Step 1: `sw.js`**

```js
const CACHE = "cli-pocket-shell-v1";
const SHELL = [
  "/",
  "/index.html",
  "/favicon.svg",
  "/manifest.webmanifest",
];
self.addEventListener("install", (e) => {
  e.waitUntil(caches.open(CACHE).then((c) => c.addAll(SHELL)));
});
self.addEventListener("activate", (e) => {
  e.waitUntil(
    caches.keys().then((keys) =>
      Promise.all(keys.filter((k) => k !== CACHE).map((k) => caches.delete(k)))
    )
  );
});
self.addEventListener("fetch", (e) => {
  if (e.request.method !== "GET") return;
  e.respondWith(
    caches.match(e.request).then((hit) => hit || fetch(e.request))
  );
});
```
