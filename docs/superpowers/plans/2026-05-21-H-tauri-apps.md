# Tauri Desktop + Mobile Apps Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship two Tauri 2.x applications (`apps/desktop`, `apps/mobile`) that embed the webview/terminal frontend (Plan G, `dist/tauri/` build) and wire it to the native `client-core` (Plan F) via Tauri commands. Desktop targets Windows / macOS / Linux. Mobile targets Android and iOS. Both expose the exact command surface promised in Plan G — `cli_pocket:{connect, create_terminal, send_input, resize, kill, export_identity, import_identity, close}` — and emit `cli_pocket:event` with `ClientEvent` JSON.

**Architecture:** Each app is a Tauri project. The Rust side (`src-tauri/`) owns a singleton `AppState` containing a `ClientSession` from `client-core`. Tauri command handlers translate `invoke` calls into `SessionCommand` messages on a `tokio::sync::mpsc` channel; a background task pumps `ClientEvent`s from the session and re-emits them as `tauri::AppHandle::emit("cli_pocket:event", …)`. Native traits required by `client-core` (Plan F) — `Transport`, `Clock`, `Rng`, `KeyValueStore` — are implemented in a small `tauri-bindings` crate shared between desktop and mobile. The frontend bundle (`webview/terminal/dist/tauri/`) is copied/symlinked as the Tauri `frontendDist`.

**Tech Stack:**
- Tauri 2.1.x (`tauri` 2.1, `tauri-build` 2, `tauri-plugin-deep-link` 2 for pairing URL scheme)
- Tokio 1 (multi-thread runtime on desktop; current-thread on mobile per Tauri 2 mobile constraints)
- `tokio-tungstenite` 0.24 (native Transport)
- `directories` 5 (XDG-friendly identity store path)
- `serde` / `serde_json` 1 (Tauri command payloads, ClientEvent JSON shape mirrors Plan G `events.ts`)
- `tracing` + `tracing-subscriber` 0.3 for logs

```rust
use async_trait::async_trait;
use cli_pocket_client_core::{Transport, TransportError};
use futures_util::{SinkExt, StreamExt};
use std::sync::Arc;
use tokio::net::TcpStream;
use tokio::sync::Mutex;
use tokio_tungstenite::tungstenite::handshake::client::Request;
use tokio_tungstenite::tungstenite::Message;
use tokio_tungstenite::{connect_async, MaybeTlsStream, WebSocketStream};

type Ws = WebSocketStream<MaybeTlsStream<TcpStream>>;

pub struct TokioWsTransport {
    inner: Arc<Mutex<Ws>>,
}

impl TokioWsTransport {
    /// Connect to a WebSocket URL. `subprotocol` selects e.g.
    /// "cli-pocket-relay-client/v1" or the daemon's host subprotocol.
    pub async fn connect(url: &str, subprotocol: Option<&str>) -> Result<Self, TransportError> {
        let mut req = Request::builder()
            .uri(url)
            .body(())
            .map_err(|e| TransportError::Connect(e.to_string()))?;
        if let Some(sp) = subprotocol {
            req.headers_mut().insert(
                "Sec-WebSocket-Protocol",
                sp.parse().map_err(|_| TransportError::Connect("bad subprotocol".into()))?,
            );
        }
        let (stream, _resp) = connect_async(req)
            .await
            .map_err(|e| TransportError::Connect(e.to_string()))?;
        Ok(Self { inner: Arc::new(Mutex::new(stream)) })
    }
}

#[async_trait(?Send)]
impl Transport for TokioWsTransport {
    async fn send(&mut self, bytes: Vec<u8>) -> Result<(), TransportError> {
        let mut g = self.inner.lock().await;
        g.send(Message::Binary(bytes))
            .await
            .map_err(|e| TransportError::Send(e.to_string()))
    }

    async fn recv(&mut self) -> Result<Vec<u8>, TransportError> {
        let mut g = self.inner.lock().await;
        loop {
            match g.next().await {
                Some(Ok(Message::Binary(b))) => return Ok(b),
                Some(Ok(Message::Ping(p))) => {
                    g.send(Message::Pong(p)).await.ok();
                    continue;
                }
                Some(Ok(Message::Close(_))) | None => {
                    return Err(TransportError::Closed);
                }
                Some(Ok(_)) => continue, // ignore Text/Pong
                Some(Err(e)) => return Err(TransportError::Recv(e.to_string())),
            }
        }
    }

    async fn close(&mut self) -> Result<(), TransportError> {
        let mut g = self.inner.lock().await;
        g.close(None).await.map_err(|e| TransportError::Send(e.to_string()))
    }
}
```

Note: `Transport` is `?Send` in Plan F (browser compatibility). Native binding wraps the inner socket in `Arc<Mutex<>>` to share between the read side (pump task) and write side (command handlers).

```rust
use async_trait::async_trait;
use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
use cli_pocket_client_core::{KeyValueStore, KvError};
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;
use std::io::ErrorKind;
use std::path::{Path, PathBuf};
use std::sync::Arc;
use tokio::sync::Mutex;

#[derive(Default, Serialize, Deserialize)]
struct Disk {
    /// keys -> base64-encoded values
    entries: BTreeMap<String, String>,
}

struct Inner {
    file: PathBuf,
    mem: BTreeMap<String, Vec<u8>>,
}

#[derive(Clone)]
pub struct FileKvStore {
    inner: Arc<Mutex<Inner>>,
}

impl FileKvStore {
    /// Open at the platform data directory: `<data_dir>/cli-pocket/store.json`.
    pub fn open_default() -> Result<Self, KvError> {
        let dirs = directories::ProjectDirs::from("dev", "cli-pocket", "cli-pocket")
            .ok_or_else(|| KvError::Backend("cannot resolve data_dir".into()))?;
        Self::open_at(dirs.data_dir())
    }

    /// Open at an explicit directory (used in tests).
    pub fn open_at(dir: &Path) -> Result<Self, KvError> {
        std::fs::create_dir_all(dir).map_err(|e| KvError::Backend(e.to_string()))?;
        let file = dir.join("store.json");
        let mem = match std::fs::read(&file) {
            Ok(bytes) => {
                let disk: Disk = serde_json::from_slice(&bytes)
                    .map_err(|e| KvError::Backend(format!("parse store.json: {e}")))?;
                disk.entries
                    .into_iter()
                    .map(|(k, v)| {
                        let raw = B64.decode(v.as_bytes()).unwrap_or_default();
                        (k, raw)
                    })
                    .collect()
            }
            Err(e) if e.kind() == ErrorKind::NotFound => BTreeMap::new(),
            Err(e) => return Err(KvError::Backend(e.to_string())),
        };
        Ok(Self {
            inner: Arc::new(Mutex::new(Inner { file, mem })),
        })
    }

    fn flush(inner: &Inner) -> Result<(), KvError> {
        let disk = Disk {
            entries: inner
                .mem
                .iter()
                .map(|(k, v)| (k.clone(), B64.encode(v)))
                .collect(),
        };
        let tmp = inner.file.with_extension("json.tmp");
        let bytes = serde_json::to_vec_pretty(&disk).map_err(|e| KvError::Backend(e.to_string()))?;
        std::fs::write(&tmp, bytes).map_err(|e| KvError::Backend(e.to_string()))?;
        std::fs::rename(&tmp, &inner.file).map_err(|e| KvError::Backend(e.to_string()))?;
        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;
            let _ = std::fs::set_permissions(&inner.file, std::fs::Permissions::from_mode(0o600));
        }
        Ok(())
    }
}

#[async_trait(?Send)]
impl KeyValueStore for FileKvStore {
    async fn get(&self, key: &str) -> Result<Option<Vec<u8>>, KvError> {
        let g = self.inner.lock().await;
        Ok(g.mem.get(key).cloned())
    }
    async fn put(&self, key: &str, value: &[u8]) -> Result<(), KvError> {
        let mut g = self.inner.lock().await;
        g.mem.insert(key.to_string(), value.to_vec());
        Self::flush(&g)
    }
    async fn delete(&self, key: &str) -> Result<(), KvError> {
        let mut g = self.inner.lock().await;
        g.mem.remove(key);
        Self::flush(&g)
    }
}
```

```rust
use cli_pocket_client_core::{ClientEvent, ConnectConfig, SessionCommand, SessionBuilder};
use std::sync::Arc;
use tokio::sync::{mpsc, Mutex};

pub struct SessionHandle {
    state: Arc<Mutex<State>>,
}

struct State {
    cmd_tx: Option<mpsc::Sender<SessionCommand>>,
    /// Set to Some<Receiver> by `take_event_rx`. Once taken, subsequent calls
    /// return `None` — there is only one event consumer (the Tauri event pump).
    event_rx: Option<mpsc::Receiver<ClientEvent>>,
    join: Option<tokio::task::JoinHandle<()>>,
}

impl SessionHandle {
    pub fn new_disconnected() -> Self {
        Self {
            state: Arc::new(Mutex::new(State {
                cmd_tx: None,
                event_rx: None,
                join: None,
            })),
        }
    }

    pub async fn is_connected(&self) -> bool {
        self.state.lock().await.cmd_tx.is_some()
    }

    /// Take the event receiver. Returns None if already taken or not connected.
    pub async fn take_event_rx(&self) -> Option<mpsc::Receiver<ClientEvent>> {
        self.state.lock().await.event_rx.take()
    }

    pub async fn send_command(&self, cmd: SessionCommand) -> Result<(), String> {
        let g = self.state.lock().await;
        let tx = g.cmd_tx.as_ref().ok_or_else(|| "not connected".to_string())?;
        tx.send(cmd).await.map_err(|e| e.to_string())
    }

    /// Spawn a new session. Replaces any existing one (its task is aborted).
    pub async fn connect(&self, builder: SessionBuilder, config: ConnectConfig)
        -> Result<(), String>
    {
        let mut g = self.state.lock().await;
        if let Some(j) = g.join.take() {
            j.abort();
        }
        let (cmd_tx, cmd_rx) = mpsc::channel(64);
        let (ev_tx, ev_rx) = mpsc::channel(256);
        let join = tokio::task::spawn_local(async move {
            // run_session_loop is defined in Plan F.
            cli_pocket_client_core::run_session_loop(builder, config, cmd_rx, ev_tx).await;
        });
        g.cmd_tx = Some(cmd_tx);
        g.event_rx = Some(ev_rx);
        g.join = Some(join);
        Ok(())
    }

    pub async fn shutdown(&self) {
        let mut g = self.state.lock().await;
        if let Some(tx) = g.cmd_tx.take() {
            let _ = tx.send(SessionCommand::Shutdown).await;
        }
        if let Some(j) = g.join.take() {
            let _ = j.await;
        }
        g.event_rx = None;
    }
}

impl Clone for SessionHandle {
    fn clone(&self) -> Self {
        Self { state: self.state.clone() }
    }
}
```

### Renamed-on-the-wire contract

Tauri commands take JSON. The frontend (Plan G) calls:

| invoke name              | payload (TS)                                                          |
|--------------------------|-----------------------------------------------------------------------|
| `cli_pocket:connect`     | `{ config: ConnectConfig }`                                           |
| `cli_pocket:create_terminal` | `{ params: { cols, rows, cwd?, env?, shell? } }`                 |
| `cli_pocket:send_input`  | `{ terminalId: string, bytesB64: string }`                            |
| `cli_pocket:resize`      | `{ terminalId: string, cols: number, rows: number }`                  |
| `cli_pocket:kill`        | `{ terminalId: string, signal?: string }`                             |
| `cli_pocket:export_identity` | `{}`  → returns `string` (base64 of serialized identity)         |
| `cli_pocket:import_identity` | `{ blob: string }`                                                |
| `cli_pocket:close`       | `{}`                                                                  |

Tauri command names: dash-or-colon in invoke string maps to function name (underscores). We use the Tauri convention: register handlers under their snake_case Rust names (`connect`, `create_terminal`, …) and rely on the frontend invoking them with the `cli_pocket:` prefix via the Tauri commands path mapping declared in `tauri.conf.json`.

Tauri 2 does NOT support colon-prefixed command names out of the box. We solve this by registering the commands under their plain snake_case names and exposing a single dispatcher command `__cli_pocket_invoke(name, args)`. The frontend `TauriBridge` already calls `invoke('cli_pocket:create_terminal', …)` — we install a thin command alias by registering both `cli_pocket_connect` etc. AND updating Plan G's `TauriBridge` to use that aliased name. **Decision:** keep the colon-style names in the frontend and add the alias on the Rust side via `tauri::Manager::invoke_handler` mapping. Concretely: in `lib.rs` use the `generate_handler!` macro names that match snake_case, then on the frontend update `TauriBridge` to invoke `cli_pocket_connect` etc. (without the colon). This is a single search-and-replace in Plan G's `TauriBridge`, recorded in Plan G's handoff note.

> **Handoff back to Plan G:** before running the desktop app, update `webview/terminal/src/bridge/TauriBridge.ts` to use snake_case command names (`cli_pocket_connect`, `cli_pocket_create_terminal`, …) instead of colon names. The event channel name remains `cli_pocket:event` — that is unaffected by the command-name constraint.

```rust
use cli_pocket_client_core::{

pub struct FrontendConfig {
    pub endpoint_url: String,
    pub server_public_hex: String,

#[tauri::command]
pub async fn connect(state: State<'_, AppState>, config: FrontendConfig) -> Result<(), String> {
    // Load or create identity.
    let mut id_guard = state.identity.lock().await;
    if id_guard.is_none() {
        let id = ClientIdentity::load_or_create(&state.kv, &OsRandom)
            .await
            .map_err(|e| e.to_string())?;
        *id_guard = Some(id);
    }
    let identity = id_guard.clone().unwrap();
    drop(id_guard);

    // Connect transport eagerly so handshake errors surface to the caller.
    let transport = TokioWsTransport::connect(
        &config.endpoint_url,
        Some("cli-pocket-host/v1"),
    )
    .await
    .map_err(|e| format!("transport connect: {e:?}"))?;

    let server_static = hex::decode(&config.server_public_hex)
        .map_err(|e| format!("server_public_hex: {e}"))?;
    let resume_token = match config.resume_token_hex.as_deref() {
        Some(s) => Some(hex::decode(s).map_err(|e| format!("resume_token_hex: {e}"))?),
        None => None,
    };

    let builder = SessionBuilder::new(identity)
        .with_clock(TokioClock)
        .with_rng(OsRandom)
        .with_kv(state.kv.clone());

    let cfg = ConnectConfig {
        transport: Box::new(transport),
        server_static_public: server_static,
        resume_token,
    };

    state
        .session
        .connect(builder, cfg)
        .await
        .map_err(|e| format!("session connect: {e}"))
}

pub async fn create_terminal(
    state: State<'_, AppState>,

    state
        .session
        .send_command(SessionCommand::SendInput {
            terminal_id: tid_bytes,
            data: bytes,
        })
        .await

}

    signal: Option<String>,

    let id_guard = state.identity.lock().await;
    let id = id_guard.as_ref().ok_or_else(|| "no identity loaded".to_string())?;
    let blob = id.export_serialized().map_err(|e| e.to_string())?;

    *g = Some(id);
    Ok(())
}

    state.session.shutdown().await;
    Ok(())
}
```

```rust
use crate::state::AppState;
use base64::{engine::general_purpose::STANDARD as B64, Engine as _};
use cli_pocket_client_core::ClientEvent;
use serde_json::json;
use tauri::{AppHandle, Emitter, Manager};

pub fn start(app: AppHandle) {
    tauri::async_runtime::spawn(async move {
        // Wait until the session is connected; then drain events forever.
        loop {
            let state = app.state::<AppState>();
            let rx = state.session.take_event_rx().await;
            match rx {
                Some(mut rx) => {
                    while let Some(ev) = rx.recv().await {
                        let payload = serialize_event(&ev);
                        let _ = app.emit("cli_pocket:event", payload);
                    }
                }
                None => {
                    tokio::time::sleep(std::time::Duration::from_millis(200)).await;
                }
            }
        }
    });
}

fn serialize_event(ev: &ClientEvent) -> serde_json::Value {
    match ev {
        ClientEvent::Connecting => json!({ "kind": "Connecting" }),
        ClientEvent::Connected { session_id } => json!({
            "kind": "Connected",
            "session_id": hex::encode(session_id),
        }),
        ClientEvent::Disconnected { will_retry, reason } => json!({
            "kind": "Disconnected",
            "will_retry": will_retry,
            "reason": reason,
        }),
        ClientEvent::TerminalCreated { info } => json!({
            "kind": "TerminalCreated",
            "info": {
                "terminal_id": hex::encode(&info.terminal_id),
                "cols": info.cols,
                "rows": info.rows,
                "cwd": info.cwd,
                "shell": info.shell,
                "pid": info.pid,
            }
        }),
        ClientEvent::TerminalOutput { terminal_id, stream_seq, bytes } => json!({
            "kind": "TerminalOutput",
            "terminal_id": hex::encode(terminal_id),
            "stream_seq": stream_seq,
            "bytes_b64": B64.encode(bytes),
        }),
        ClientEvent::TerminalExited { terminal_id, info } => json!({
            "kind": "TerminalExited",
            "terminal_id": hex::encode(terminal_id),
            "info": { "code": info.code, "signal": info.signal },
        }),
        ClientEvent::Error { message } => json!({ "kind": "Error", "message": message }),
    }
}
```
