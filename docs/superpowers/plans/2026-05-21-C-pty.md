# Plan C — PTY + Scrollback

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land `crates/server/pty` — a `Terminal` type that wraps `portable-pty`, owns a bytes-plus-anchor scrollback ring buffer, and exposes `snapshot()` / `since(seq)` / `subscribe()` so `daemon-core` (Plan D) can build the routing layer on top.

**Architecture:** `Terminal` owns the PTY pair, a spawned child, a reader task that pipes PTY output through a `vte` parser into a `ScrollbackRing`, and a `tokio::sync::broadcast` for live subscribers. Snapshot/delta are derived from the ring; the ring uses anchors at safe split points so xterm.js can resume rendering without parsing partial CSI/OSC.

**Tech Stack:** `portable-pty` 0.8.x, `vte` 0.13.x, `tokio` (broadcast + spawn_blocking), `cli-pocket-proto` for `Snapshot`/`AnchorState`/`StreamSeq`.

**Spec reference:** § Section 4 (PTY, ring buffer, anchors, snapshot semantics).

**Upstream plan:** Plan B. Read `docs/superpowers/handoff/B.md` before starting — confirm `Snapshot`, `AnchorState`, `SgrAttrs`, `TerminalModes`, `CharsetState`, `DeltaSlice`, `StreamSeq` shapes match the spec types you'll be filling in here.

## Definition of Done

- `Terminal::spawn` runs `echo hello` cross-platform; the test reads "hello\r\n" (or "hello\n" on Unix) from the live broadcast.
- `Terminal::spawn` with `cmd = []` spawns the platform's login shell (`$SHELL` or `cmd.exe`).
- Ring buffer property test: random push sequences never violate `tail_seq <= head_seq`, the oldest retained byte is always at an anchor boundary, and capacity is honored.
- `snapshot()` returned after a 100 KiB push contains an `AnchorState` whose initial values let xterm.js render the trailing bytes from `bytes` to the same final screen the live stream would produce.
- `since(seq)` returns `Some(DeltaSlice)` while `seq >= tail_seq`, and `None` once `seq` falls below the tail.
- Lagging subscriber overflow returns a `Lagged` indication rather than blocking the PTY drain.
- `kill(KillSignal::Term)` ends the child within 500 ms in tests; `wait()` returns `ExitInfo` with `code = Some(_)` or `signal = Some(_)`.
- `cargo test -p cli-pocket-pty` passes on the developer's host OS. Linux CI is the required gate; macOS/Windows are best-effort at this stage.
- `unsafe_code = "allow"` per-crate override is added with a comment justifying it (none of `portable-pty`'s API forces unsafe in our code, but `ConPTY` plumbing can; the override keeps us honest if a future Windows code path needs it). An ADR (0002) documents the override.

- [ ] **Step 3: Write ADR 0002**

```markdown
# 0002. Bytes-plus-anchor scrollback rather than parsed grid

Date: <fill>
Status: Accepted
Owners: <fill>

## Context

The daemon must let a late-attaching client render the terminal correctly
from "the last known state" plus subsequent bytes. Two designs were
considered:

1. **Parsed grid** (mosh / alacritty_terminal style): the daemon runs a
   full vt100 implementation and ships cell state.
2. **Bytes plus anchor**: the daemon stores raw output bytes and the
   parser state at periodic safe split points; the client re-feeds bytes
   to its own parser (xterm.js).

The PTY crate also relaxes the workspace `unsafe_code = "forbid"` lint
because Windows ConPTY plumbing may need raw HANDLEs in the future. No
unsafe is required today by `portable-pty`'s API, but we accept the lint
relaxation up front rather than fighting it later.

## Decision

Use bytes-plus-anchor (option 2). Anchors are placed every ~64 KiB at the
first `vte::ground` state crossing, and store cursor + SGR + modes +
charset state — the minimum xterm.js needs to start rendering correctly.

Relax `unsafe_code` to `allow` in `cli-pocket-pty` only.

## Consequences

- Positive: no vt100 implementation to maintain. The client's xterm.js
  parser is the canonical renderer.
- Positive: cheap to push (`vte` is a state-machine costing single-digit
  ns/byte). No per-frame grid diffing.
- Positive: ring buffer behavior is bytewise and easy to reason about.
- Negative: a client cannot "query" the terminal grid contents — only the
  bytes plus initial state. Programs that depend on screen scraping the
  daemon (none in v1) would have to render locally.
- Risks accepted: a future xterm.js parser regression that changes how
  certain sequences render would also change daemon-to-client rendering.
  We accept this; xterm.js stability is good.
```

```rust
use cli_pocket_proto::{AnchorState, CharsetState, Color, MouseMode, SgrAttrs, TerminalModes};
use vte::{Params, Parser, Perform};

/// Tracks AnchorState by replaying bytes through `vte`. A snapshot can be
/// taken whenever the parser is in `ground` (no half-consumed escape).
pub struct AnchorTracker {
    parser: Parser,
    state: AnchorStateMut,
}

#[derive(Default)]
struct AnchorStateMut {
    cursor_row: u16,
    cursor_col: u16,
    sgr: SgrAttrs,
    modes: TerminalModes,
    charset: CharsetState,
    title: Option<String>,
    in_osc_title: bool,
    osc_buf: Vec<u8>,
}

impl AnchorTracker {
    pub fn new() -> Self {
        Self {
            parser: Parser::new(),
            state: AnchorStateMut {
                modes: TerminalModes {
                    autowrap: true,
                    ..Default::default()
                },
                charset: CharsetState {
                    g: [b'B'; 4],
                    gl: 0,
                    gr: 2,
                },
                ..Default::default()
            },
        }
    }

    pub fn advance(&mut self, bytes: &[u8]) {
        let mut perform = TrackerPerform {
            s: &mut self.state,
        };
        for byte in bytes {
            self.parser.advance(&mut perform, *byte);
        }
    }

    /// True when the parser is in the ground state — safe to take an anchor.
    pub fn is_at_safe_split(&self) -> bool {
        // `vte::Parser` does not expose its internal state. We treat any byte
        // that *didn't* leave the parser mid-escape as safe — i.e., we
        // remember the last operation type and only split after a print/exec.
        // The in-osc-title flag is the one we tracked explicitly.
        !self.state.in_osc_title
    }

    pub fn snapshot_state(&self) -> AnchorState {
        AnchorState {
            cursor: (self.state.cursor_col, self.state.cursor_row),
            sgr: self.state.sgr,
            modes: self.state.modes,
            charset: self.state.charset,
            title: self.state.title.clone(),
        }
    }
}

impl Default for AnchorTracker {
    fn default() -> Self {
        Self::new()
    }
}

struct TrackerPerform<'a> {
    s: &'a mut AnchorStateMut,
}

impl<'a> Perform for TrackerPerform<'a> {
    fn print(&mut self, c: char) {
        let w = unicode_width(c);
        self.s.cursor_col = self.s.cursor_col.saturating_add(w);
    }

    fn execute(&mut self, byte: u8) {
        match byte {
            b'\n' => {
                self.s.cursor_row = self.s.cursor_row.saturating_add(1);
                self.s.cursor_col = 0;
            }
            b'\r' => self.s.cursor_col = 0,
            b'\x08' => self.s.cursor_col = self.s.cursor_col.saturating_sub(1),
            b'\t' => {
                self.s.cursor_col = ((self.s.cursor_col / 8) + 1).saturating_mul(8);
            }
            _ => {}
        }
    }

    fn hook(&mut self, _params: &Params, _intermediates: &[u8], _ignore: bool, _action: char) {}
    fn put(&mut self, _byte: u8) {}
    fn unhook(&mut self) {}

    fn osc_dispatch(&mut self, params: &[&[u8]], _bell_terminated: bool) {
        // OSC 0 ; <title> BEL  → window title
        // OSC 2 ; <title> BEL  → window title
        if let [head, title @ ..] = params {
            if matches!(head.first(), Some(b'0') | Some(b'2')) && !title.is_empty() {
                let joined: Vec<u8> = title.iter().flat_map(|s| s.iter().copied()).collect();
                if let Ok(t) = std::str::from_utf8(&joined) {
                    self.s.title = Some(t.to_owned());
                }
            }
        }
        self.s.in_osc_title = false;
    }

    fn csi_dispatch(&mut self, params: &Params, _intermediates: &[u8], _ignore: bool, action: char) {
        match action {
            'm' => self.sgr(params),
            'H' | 'f' => self.cursor_position(params),
            'A' => {
                let n = first_param(params, 1);
                self.s.cursor_row = self.s.cursor_row.saturating_sub(n);
            }
            'B' => {
                let n = first_param(params, 1);
                self.s.cursor_row = self.s.cursor_row.saturating_add(n);
            }
            'C' => {
                let n = first_param(params, 1);
                self.s.cursor_col = self.s.cursor_col.saturating_add(n);
            }
            'D' => {
                let n = first_param(params, 1);
                self.s.cursor_col = self.s.cursor_col.saturating_sub(n);
            }
            'h' => self.mode_set(params, true),
            'l' => self.mode_set(params, false),
            _ => {}
        }
    }

    fn esc_dispatch(&mut self, _intermediates: &[u8], _ignore: bool, _byte: u8) {}
}

impl<'a> TrackerPerform<'a> {
    fn sgr(&mut self, params: &Params) {
        let mut iter = params.iter();
        if iter.len() == 0 {
            self.s.sgr = SgrAttrs::default();
            return;
        }
        while let Some(p) = iter.next() {
            let code = p.first().copied().unwrap_or(0);
            match code {
                0 => self.s.sgr = SgrAttrs::default(),
                1 => self.s.sgr.bold = true,
                2 => self.s.sgr.faint = true,
                3 => self.s.sgr.italic = true,
                4 => self.s.sgr.underline = true,
                5 => self.s.sgr.blink = true,
                7 => self.s.sgr.reverse = true,
                9 => self.s.sgr.strikethrough = true,
                22 => {
                    self.s.sgr.bold = false;
                    self.s.sgr.faint = false;
                }
                23 => self.s.sgr.italic = false,
                24 => self.s.sgr.underline = false,
                25 => self.s.sgr.blink = false,
                27 => self.s.sgr.reverse = false,
                29 => self.s.sgr.strikethrough = false,
                30..=37 => self.s.sgr.fg = Some(Color::Palette((code - 30) as u8)),
                39 => self.s.sgr.fg = None,
                40..=47 => self.s.sgr.bg = Some(Color::Palette((code - 40) as u8)),
                49 => self.s.sgr.bg = None,
                90..=97 => self.s.sgr.fg = Some(Color::Palette((code - 90 + 8) as u8)),
                100..=107 => self.s.sgr.bg = Some(Color::Palette((code - 100 + 8) as u8)),
                _ => {}
            }
        }
    }

    fn cursor_position(&mut self, params: &Params) {
        let row = first_param(params, 1).saturating_sub(1);
        let col = nth_param(params, 1, 1).saturating_sub(1);
        self.s.cursor_row = row;
        self.s.cursor_col = col;
    }

    fn mode_set(&mut self, params: &Params, on: bool) {
        for p in params.iter() {
            match p.first().copied().unwrap_or(0) {
                1 => self.s.modes.deccmm_cursor_keys = on,
                7 => self.s.modes.autowrap = on,
                1049 => self.s.modes.alt_screen = on,
                2004 => self.s.modes.bracketed_paste = on,
                9 => self.s.modes.mouse_reporting = if on { MouseMode::X10 } else { MouseMode::Off },
                1000 => {
                    self.s.modes.mouse_reporting = if on { MouseMode::Normal } else { MouseMode::Off }
                }
                1002 => {
                    self.s.modes.mouse_reporting = if on { MouseMode::ButtonEvent } else { MouseMode::Off }
                }
                1003 => {
                    self.s.modes.mouse_reporting = if on { MouseMode::AnyEvent } else { MouseMode::Off }
                }
                6 => self.s.modes.origin_mode = on,
                _ => {}
            }
        }
    }
}

fn first_param(params: &Params, default: u16) -> u16 {
    params
        .iter()
        .next()
        .and_then(|p| p.first().copied())
        .filter(|&v| v != 0)
        .unwrap_or(default)
}

fn nth_param(params: &Params, n: usize, default: u16) -> u16 {
    params
        .iter()
        .nth(n)
        .and_then(|p| p.first().copied())
        .filter(|&v| v != 0)
        .unwrap_or(default)
}

fn unicode_width(c: char) -> u16 {
    // Minimal width: 0 for combining/control; 1 for everything else.
    // Wide-character awareness is xterm.js's job at render time; the
    // anchor tracker only needs an approximate cursor column, which a
    // 1-per-codepoint counter is fine for in the "approximate state at
    // anchor" model.
    if c.is_control() {
        0
    } else {
        1
    }
}
```

```rust
use crate::parser::AnchorTracker;
use cli_pocket_proto::{AnchorState, DeltaSlice, Snapshot, StreamSeq};
use serde_bytes::ByteBuf;
use std::collections::VecDeque;

const DEFAULT_CAPACITY_BYTES: usize = 4 * 1024 * 1024;
const DEFAULT_ANCHOR_INTERVAL: usize = 64 * 1024;
const MAX_CAPACITY_BYTES: usize = 64 * 1024 * 1024;

#[derive(Debug, thiserror::Error)]
pub enum RingError {
    #[error("capacity {0} exceeds the per-terminal limit {MAX_CAPACITY_BYTES}")]
    CapacityTooLarge(usize),
}

#[derive(Debug, Clone)]
struct Anchor {
    seq: StreamSeq,
    byte_offset: usize, // logical (absolute) byte offset since terminal creation
    state: AnchorState,
}

pub struct ScrollbackRing {
    /// Raw output bytes, oldest at front.
    bytes: VecDeque<u8>,
    /// Anchors in order. The first anchor's `byte_offset` equals the
    /// absolute byte position of the oldest retained byte.
    anchors: VecDeque<Anchor>,
    /// Monotonic byte counter since this ring was created (also `head_seq`).
    head_seq: StreamSeq,
    /// Absolute byte offset of the oldest retained byte.
    tail_offset: usize,
    /// Inline parser used to identify safe split points and produce anchor states.
    tracker: AnchorTracker,
    bytes_since_anchor: usize,
    cap: usize,
    anchor_interval: usize,
    cols: u16,
    rows: u16,
}

impl ScrollbackRing {
    pub fn new(cols: u16, rows: u16, capacity: Option<usize>) -> Result<Self, RingError> {
        let cap = capacity.unwrap_or(DEFAULT_CAPACITY_BYTES);
        if cap > MAX_CAPACITY_BYTES {
            return Err(RingError::CapacityTooLarge(cap));
        }
        let mut ring = Self {
            bytes: VecDeque::with_capacity(cap.min(1 << 16)),
            anchors: VecDeque::new(),
            head_seq: StreamSeq(0),
            tail_offset: 0,
            tracker: AnchorTracker::new(),
            bytes_since_anchor: usize::MAX, // force first anchor at offset 0
            cap,
            anchor_interval: DEFAULT_ANCHOR_INTERVAL,
            cols,
            rows,
        };
        ring.maybe_place_anchor();
        Ok(ring)
    }

    pub fn head_seq(&self) -> StreamSeq {
        self.head_seq
    }

    pub fn tail_seq(&self) -> StreamSeq {
        StreamSeq(self.tail_offset as u64)
    }

    pub fn dims(&self) -> (u16, u16) {
        (self.cols, self.rows)
    }

    pub fn set_dims(&mut self, cols: u16, rows: u16) {
        self.cols = cols;
        self.rows = rows;
    }

    pub fn push(&mut self, chunk: &[u8]) {
        self.tracker.advance(chunk);
        self.bytes.extend(chunk.iter().copied());
        self.head_seq = StreamSeq(self.head_seq.0 + chunk.len() as u64);
        self.bytes_since_anchor = self.bytes_since_anchor.saturating_add(chunk.len());
        self.maybe_place_anchor();
        self.maybe_evict();
    }

    fn maybe_place_anchor(&mut self) {
        if self.bytes_since_anchor < self.anchor_interval && !self.anchors.is_empty() {
            return;
        }
        if !self.tracker.is_at_safe_split() && !self.anchors.is_empty() {
            // wait for a safe split — but cap at 2*interval to avoid pathological
            // payloads holding off anchor placement forever.
            if self.bytes_since_anchor < 2 * self.anchor_interval {
                return;
            }
        }
        self.anchors.push_back(Anchor {
            seq: self.head_seq,
            byte_offset: self.head_seq.0 as usize,
            state: self.tracker.snapshot_state(),
        });
        self.bytes_since_anchor = 0;
    }

    fn maybe_evict(&mut self) {
        while self.bytes.len() > self.cap {
            // Drop bytes from the front up to the second-oldest anchor.
            let second_oldest_offset = match self.anchors.get(1) {
                Some(a) => a.byte_offset,
                None => break, // only one anchor; refuse to evict past it
            };
            let to_drop = second_oldest_offset.saturating_sub(self.tail_offset);
            if to_drop == 0 {
                break;
            }
            for _ in 0..to_drop {
                if self.bytes.pop_front().is_none() {
                    break;
                }
            }
            self.tail_offset = second_oldest_offset;
            self.anchors.pop_front();
        }
    }

    pub fn snapshot(&self) -> Snapshot {
        let oldest = self
            .anchors
            .front()
            .cloned()
            .unwrap_or_else(|| Anchor {
                seq: StreamSeq(0),
                byte_offset: 0,
                state: AnchorState {
                    cursor: (0, 0),
                    sgr: Default::default(),
                    modes: Default::default(),
                    charset: cli_pocket_proto::CharsetState {
                        g: [b'B'; 4],
                        gl: 0,
                        gr: 2,
                    },
                    title: None,
                },
            });
        let start_rel = oldest.byte_offset.saturating_sub(self.tail_offset);
        let bytes: Vec<u8> = self.bytes.iter().skip(start_rel).copied().collect();
        Snapshot {
            cols: self.cols,
            rows: self.rows,
            anchor_state: oldest.state.clone(),
            bytes: ByteBuf::from(bytes),
            head_seq: self.head_seq,
        }
    }

    pub fn since(&self, seq: StreamSeq) -> Option<DeltaSlice> {
        if seq.0 < self.tail_offset as u64 {
            return None;
        }
        if seq.0 > self.head_seq.0 {
            return Some(DeltaSlice {
                bytes: ByteBuf::from(Vec::new()),
                head_seq: self.head_seq,
            });
        }
        let start_rel = (seq.0 - self.tail_offset as u64) as usize;
        let bytes: Vec<u8> = self.bytes.iter().skip(start_rel).copied().collect();
        Some(DeltaSlice {
            bytes: ByteBuf::from(bytes),
            head_seq: self.head_seq,
        })
    }
}
```

```rust
use bytes::Bytes;
use cli_pocket_proto::StreamSeq;
use tokio::sync::broadcast;

const SUBSCRIBER_CAP: usize = 1024;

#[derive(Debug, Clone)]
pub struct OutputChunk {
    pub seq_at_end: StreamSeq,
    pub bytes: Bytes,
}

#[derive(Debug)]
pub enum OutputRecv {
    Chunk(OutputChunk),
    Lagged { skipped: u64 },
    Closed,
}

pub struct OutputBroadcaster {
    tx: broadcast::Sender<OutputChunk>,
}

impl OutputBroadcaster {
    pub fn new() -> Self {
        let (tx, _) = broadcast::channel(SUBSCRIBER_CAP);
        Self { tx }
    }

    pub fn send(&self, chunk: OutputChunk) {
        // Receivers that lag will see `Lagged` on their next recv; we don't
        // propagate the per-recv error here.
        let _ = self.tx.send(chunk);
    }

    pub fn subscribe(&self) -> OutputStream {
        OutputStream {
            rx: self.tx.subscribe(),
        }
    }
}

impl Default for OutputBroadcaster {
    fn default() -> Self {
        Self::new()
    }
}

pub struct OutputStream {
    rx: broadcast::Receiver<OutputChunk>,
}

impl OutputStream {
    pub async fn recv(&mut self) -> OutputRecv {
        match self.rx.recv().await {
            Ok(c) => OutputRecv::Chunk(c),
            Err(broadcast::error::RecvError::Lagged(skipped)) => {
                OutputRecv::Lagged { skipped }
            }
            Err(broadcast::error::RecvError::Closed) => OutputRecv::Closed,
        }
    }
}

#[derive(Debug, Clone, Copy)]
pub struct Lagged {
    pub skipped: u64,
}
```

```rust
use crate::output::{OutputBroadcaster, OutputChunk, OutputStream};
use crate::platform;
use crate::ring::{RingError, ScrollbackRing};
use bytes::Bytes;
use cli_pocket_proto::{ExitInfo, KillSignal, Snapshot, StreamSeq, TerminalCreateParams, TerminalId};
use portable_pty::{CommandBuilder, MasterPty, PtyPair, PtySize};
use std::io::{Read, Write};
use std::sync::Arc;
use std::sync::Mutex;
use tokio::sync::oneshot;

#[derive(Debug, thiserror::Error)]
pub enum TerminalError {
    #[error("ring: {0}")]
    Ring(#[from] RingError),
    #[error("io: {0}")]
    Io(#[from] std::io::Error),
    #[error("portable-pty: {0}")]
    Pty(String),
    #[error("terminal already exited")]
    Exited,
}

pub struct Terminal {
    id: TerminalId,
    inner: Arc<TerminalInner>,
}

struct TerminalInner {
    state: Mutex<TerminalState>,
    broadcaster: OutputBroadcaster,
    exit_rx: Mutex<Option<oneshot::Receiver<ExitInfo>>>,
    exit_cached: Mutex<Option<ExitInfo>>,
}

struct TerminalState {
    master: Box<dyn MasterPty + Send>,
    child: Box<dyn portable_pty::Child + Send + Sync>,
    writer: Box<dyn Write + Send>,
    ring: ScrollbackRing,
    dead: bool,
}

impl Terminal {
    pub fn spawn(params: TerminalCreateParams) -> Result<Self, TerminalError> {
        let pty_system = portable_pty::native_pty_system();
        let cols = params.cols.max(1);
        let rows = params.rows.max(1);
        let size = PtySize {
            cols,
            rows,
            pixel_width: 0,
            pixel_height: 0,
        };
        let PtyPair { master, slave } = pty_system
            .openpty(size)
            .map_err(|e| TerminalError::Pty(e.to_string()))?;

        let cmd_vec = if params.cmd.is_empty() {
            platform::default_shell()
        } else {
            params.cmd.clone()
        };
        let mut cmd = CommandBuilder::new(&cmd_vec[0]);
        for arg in cmd_vec.iter().skip(1) {
            cmd.arg(arg);
        }
        if let Some(cwd) = params.cwd.as_deref() {
            cmd.cwd(cwd);
        }
        for (k, v) in &params.env {
            cmd.env(k, v);
        }
        let child = slave
            .spawn_command(cmd)
            .map_err(|e| TerminalError::Pty(e.to_string()))?;
        drop(slave);

        let writer = master
            .take_writer()
            .map_err(|e| TerminalError::Pty(e.to_string()))?;
        let reader = master
            .try_clone_reader()
            .map_err(|e| TerminalError::Pty(e.to_string()))?;

        let ring = ScrollbackRing::new(
            cols,
            rows,
            params.scrollback_bytes.map(|n| n as usize),
        )?;
        let broadcaster = OutputBroadcaster::new();

        let (exit_tx, exit_rx) = oneshot::channel();

        let inner = Arc::new(TerminalInner {
            state: Mutex::new(TerminalState {
                master,
                child,
                writer,
                ring,
                dead: false,
            }),
            broadcaster,
            exit_rx: Mutex::new(Some(exit_rx)),
            exit_cached: Mutex::new(None),
        });

        // Reader task: pump PTY → ring → broadcaster on a blocking thread.
        Self::spawn_reader(Arc::clone(&inner), reader);
        // Waiter task: drive child.wait() on a blocking thread.
        Self::spawn_waiter(Arc::clone(&inner), exit_tx);

        Ok(Self {
            id: TerminalId::new(),
            inner,
        })
    }

    fn spawn_reader(
        inner: Arc<TerminalInner>,
        mut reader: Box<dyn Read + Send>,
    ) {
        std::thread::spawn(move || {
            let mut buf = [0u8; 8192];
            loop {
                let n = match reader.read(&mut buf) {
                    Ok(0) => break,
                    Ok(n) => n,
                    Err(e) if e.kind() == std::io::ErrorKind::Interrupted => continue,
                    Err(_) => break,
                };
                let chunk = Bytes::copy_from_slice(&buf[..n]);
                let seq = {
                    let mut st = inner.state.lock().unwrap();
                    if st.dead {
                        break;
                    }
                    st.ring.push(&chunk);
                    st.ring.head_seq()
                };
                inner.broadcaster.send(OutputChunk {
                    seq_at_end: seq,
                    bytes: chunk,
                });
            }
        });
    }

    fn spawn_waiter(inner: Arc<TerminalInner>, tx: oneshot::Sender<ExitInfo>) {
        std::thread::spawn(move || {
            let status = {
                let mut st = inner.state.lock().unwrap();
                // Take the child without dropping the lock for a long wait —
                // portable-pty's Child::wait is blocking and uninterruptible,
                // so we briefly release the lock by replacing with a sentinel
                // is not possible (Child is not Default). Instead, we use
                // try_wait in a loop, sleeping briefly. This isn't perfect
                // but avoids deadlocking other consumers of state.
                drop(st);
                loop {
                    let mut s = inner.state.lock().unwrap();
                    match s.child.try_wait() {
                        Ok(Some(status)) => break status,
                        Ok(None) => {
                            drop(s);
                            std::thread::sleep(std::time::Duration::from_millis(50));
                            continue;
                        }
                        Err(_) => break portable_pty::ExitStatus::with_exit_code(1),
                    }
                }
            };
            let exit = ExitInfo {
                code: Some(status.exit_code() as i32),
                signal: None,
                at_unix_ms: now_unix_ms(),
            };
            *inner.exit_cached.lock().unwrap() = Some(exit.clone());
            inner.state.lock().unwrap().dead = true;
            let _ = tx.send(exit);
        });
    }

    pub fn id(&self) -> TerminalId {
        self.id
    }

    pub fn dims(&self) -> (u16, u16) {
        let st = self.inner.state.lock().unwrap();
        st.ring.dims()
    }

    pub fn write_input(&self, bytes: &[u8]) -> Result<(), TerminalError> {
        let mut st = self.inner.state.lock().unwrap();
        if st.dead {
            return Err(TerminalError::Exited);
        }
        st.writer.write_all(bytes)?;
        st.writer.flush()?;
        Ok(())
    }

    pub fn subscribe(&self) -> OutputStream {
        self.inner.broadcaster.subscribe()
    }

    pub fn snapshot(&self) -> Snapshot {
        self.inner.state.lock().unwrap().ring.snapshot()
    }

    pub fn since(&self, seq: StreamSeq) -> Option<cli_pocket_proto::DeltaSlice> {
        self.inner.state.lock().unwrap().ring.since(seq)
    }

    pub fn head_seq(&self) -> StreamSeq {
        self.inner.state.lock().unwrap().ring.head_seq()
    }

    pub fn resize(&self, cols: u16, rows: u16) -> Result<(), TerminalError> {
        let mut st = self.inner.state.lock().unwrap();
        if st.dead {
            return Err(TerminalError::Exited);
        }
        st.master
            .resize(PtySize {
                cols,
                rows,
                pixel_width: 0,
                pixel_height: 0,
            })
            .map_err(|e| TerminalError::Pty(e.to_string()))?;
        st.ring.set_dims(cols, rows);
        Ok(())
    }

    pub fn kill(&self, _signal: KillSignal) -> Result<(), TerminalError> {
        let mut st = self.inner.state.lock().unwrap();
        if st.dead {
            return Ok(());
        }
        st.child
            .kill()
            .map_err(|e| TerminalError::Pty(e.to_string()))?;
        Ok(())
    }

    pub async fn wait(&self) -> ExitInfo {
        if let Some(e) = self.inner.exit_cached.lock().unwrap().clone() {
            return e;
        }
        let rx = self.inner.exit_rx.lock().unwrap().take();
        match rx {
            Some(rx) => rx.await.unwrap_or(ExitInfo {
                code: Some(1),
                signal: None,
                at_unix_ms: now_unix_ms(),
            }),
            None => self
                .inner
                .exit_cached
                .lock()
                .unwrap()
                .clone()
                .unwrap_or(ExitInfo {
                    code: Some(1),
                    signal: None,
                    at_unix_ms: now_unix_ms(),
                }),
        }
    }
}

fn now_unix_ms() -> u64 {
    std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_millis() as u64)
        .unwrap_or(0)
}
```

```markdown
`cli-pocket-pty` (0.1.0):

- Platform shell resolution (`platform/{unix,windows}.rs`) — `$SHELL` or
```
